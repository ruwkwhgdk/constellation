# Heroine — 제작 및 검증 기록

**상태: 검토용 1차 모델. 요청한 고품질 상용 서브컬처 게임 수준의 완성본은 아닙니다.**

원화의 의상·색상·비대칭 단발을 바탕으로 Blender에서 모델을 구성했습니다. 얼굴의 인상, 머리카락 끝선, 의상 주름과 손·신발 디테일은 추가적인 아트 작업이 필요합니다. 현재 파일을 기존 플레이어 모델의 최종 교체본으로 취급하면 안 됩니다.

## 파일

- `Heroine_Rebuild.blend`: 편집 가능한 파츠, 패킹된 텍스처, 조명·카메라, 팔을 내린 검토 포즈. Blender 5.2.1 LTS에서 저장하고 다시 열어 렌더했습니다.
- `Heroine_Rebuild.fbx`: 원본 바인드 포즈, 통합된 스킨드 메시 1개와 원본 스켈레톤. 텍스처 포함.
- `textures/`: 얼굴·홍채·헤어·니트·체크무늬 PNG 텍스처. 단색 재질도 사용합니다.
- `renders/`: 정면, 측면, 후면, 3/4, 얼굴 확대, 관절 포즈 확인 이미지.
- `validation.json`: FBX를 별도 Blender 프로세스에서 다시 불러와 측정한 결과.
- `scripts/`: 원본 조사, 제작, FBX 검사, 포즈 확인을 재현하는 스크립트.

## 제작 범위

새로 구성한 부분: 얼굴, 눈·눈꺼풀·홍채, 단발 헤어, 목, 다섯 손가락 형태의 손, 카디건 몸판·소매·포켓·밑단, 셔츠·깃·리본, 체크 플리츠 스커트, 머리핀·팔찌·단추.

재사용한 부분: 원본 하체·신발의 형상과 원본 스켈레톤. 원본 체형과 바인드 위치를 참고했으며, 일부 의상 웨이트는 원본에서 샘플링하고 몸판·소매는 별도로 배분했습니다.

Unreal의 `Content/Resources/Characters/PC/Player_Heroine` 에셋과 원본 FBX는 변경하지 않았습니다.

## 확인 범위와 남은 작업

- Blender에서 전후좌우 실루엣, 재질 연결과 기본 팔·무릎 굽힘을 확인했습니다. 프로젝트의 실제 애니메이션 전체를 재생한 검증은 수행하지 않았습니다.
- 큰 다리 동작에서는 스커트·카디건의 겹침과 옷 변형 보정이 필요합니다. 현재 의상에 물리 시뮬레이션은 없습니다.
- 손가락은 손 본을 따라 움직입니다. 개별 손가락 관절 리깅은 없습니다.
- 표정 블렌드셰이프, 눈 깜빡임·시선 제어, 헤어 물리, LOD 체계는 포함하지 않았습니다.
- 재질 슬롯 24개는 검토·편집 편의를 위한 구성입니다. 멀티플랫폼 배포 전에 아틀라스 통합과 재질/드로콜 최적화가 필요합니다.
- 렌더는 Blender의 재질·조명을 사용했습니다. Unreal용 셀 셰이더, 윤곽선, 얼굴 그림자 제어는 아직 구현하지 않았습니다.
- 피부·헤어의 미술적 정리와 손·신발·의상 디테일 보강이 필요합니다. 이 결과를 명조급 품질로 표현하지 않습니다.

## 재현

프로젝트 루트에서 설치된 Blender로 `scripts/build_heroine.py`를 실행하면 모델과 렌더를 다시 생성합니다. 스크립트는 사용자의 기존 원본 FBX 경로를 참조합니다. `-- --quick` 인자는 낮은 해상도의 정면·얼굴 렌더만 만듭니다.

`scripts/validate_export.py`는 저장된 FBX를 독립적으로 재임포트합니다. `scripts/pose_check.py`는 저장된 Blend를 다시 열어 포즈를 렌더하며 원본 Blend에는 포즈 변경을 저장하지 않습니다.
