# 사용자 지정 작업 기준

2026-09-20 피드백: 원본의 애니메 눈썹·눈꺼풀·속눈썹 디테일과 캐릭터의 인상을 보존한다. 오류 정리를 이유로 이를 단색 선이나 단순한 형태로 교체하지 않는다.

형태, 재질 또는 텍스처를 교체하는 큰 재작업은 실행 전에 변경 이유, 보존할 특징, 예상되는 인상 변화와 범위를 자세히 설명하고 사용자 확인을 받는다. 미세 보정과 디자인 교체를 구분한다.

`FaceClean`은 사용자가 표현 단순화를 지적한 버전이다. 후속 작업의 기본으로 자동 선택하지 않는다. `DetailPreserved`는 사용자가 첨부한 `Refined`의 눈 표현을 복원한 버전이다.
