# 애니메이션 Legacy 정리 기록

사용자 요청으로 RunNatural, RunRetarget, RunPolish 초안 소스 폴더와 RunSoft의 이전 초안 의존 준비 스크립트를 제거했다. 파일 삭제 목록은 `source_cleanup_manifest.json` 및 `remaining_cleanup_manifest.json`에 있다. 두 목록 합계 208개 파일, 816,803,252 bytes(약 817MB)이며 엔진 API로 삭제한 애니메이션 uasset 3개 용량은 별도다.

언리얼에서 제거한 항목:

- `AS_player_heroine_new_Run_Natural`
- `AS_player_heroine_new_Run_Retarget`
- `AS_player_heroine_new_Run_Polish`
- `L_player_heroine_new_Run_Natural`
- `L_player_heroine_new_Run_Polish`

Asset Registry의 hard/soft 참조를 확인했으며 초안 맵 이외의 사용처는 없었다. 엔진 API가 맵 삭제 성공을 반환하고도 .umap을 남겨, 확인된 두 파일만 경로 검증 후 제거했다. 새 엔진 프로세스의 최종 확인 결과는 `cleanup_verified.json`에 기록한다.

유지한 항목:

- RunSoft의 편집 원본·FBX·미리보기·검증 자료. 최종 애니메이션 FBX SHA256은 정리 전후 동일하다.
- WalkTimid와 기존 프리뷰 포즈, 원본 게임 Walk/Run 및 ABP/Blend Space.
- `SK_player_heroine_new_RunPreview`의 FBX·텍스처·치마 웨이트 자료는 RunSoft로 이동했다. 원본과 복사본 해시를 대조했고 엔진 재임포트 경로도 갱신했다.
- 모델링 원본, 텍스처, RigReferenceFit 게임 스켈레톤 및 익스포터.
- `ReferenceMotion/`: 기존 게임 Run에서 추출한 FBX·모션 샘플·rest pose 자료.
- `ConnectionBackups/`: Blender MCP 연결 전 사용자 설정과 이전 애드온 백업. 애니메이션 초안이 아닌 복구 자료이므로 유지했다.

`RunSoft/finish.py`의 과거 폴더 의존성을 없애고 실행을 확인했다. 현재 Blender 파일의 파일 이미지 22개는 내장되었거나 실제 경로가 존재하며 외부 blend library 의존성은 없다. 다음 애니메이션 작업은 `SKILL.md`를 읽고 현재 최종 원본에서 시작한다.
