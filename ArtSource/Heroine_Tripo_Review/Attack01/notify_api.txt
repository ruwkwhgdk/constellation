X.add_animation_notify_event_from_source(animation_sequence_base, start_time, notify_event, notify_track_name) -> AnimNotify

Experimental: Adds a custom animation notify event to the specified animation sequence at the given time and on the specified notify track.

A new notify event will be created using relevant data copied from the provided NotifyEvent. The UAnimNotify is extracted from
NotifyEvent and, if it is not already owned by the animation sequence (not part of its outer), it will be automatically duplicated.
Only properties exposed to Blueprints in the NotifyEvent (such as TriggerWeightThreshold and NotifyTriggerChance) will be copied.



Args:

    animation_sequence_base (AnimSequenceBase): The animation sequence to which the new notify event will be added.

    start_time (float): The time (in seconds) within the sequence where the notify should be placed.

    notify_event (AnimNotifyEvent): The source notify event used to initialize the new one. Its UAnimNotify will be extracted and validated.

    notify_track_name (Name): The name of the notify track to add the notify to.



Returns:

    AnimNotify: The UAnimNotify used in the new notify event (original or duplicated).
