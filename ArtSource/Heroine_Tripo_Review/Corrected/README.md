# Heroine — Tripo 모델 1차 보정

원본 원화 `heroine_illust.png`를 디자인 기준으로 삼고, 제공된 Tripo 메시와 UV를 유지하면서 보정했습니다. 피규어 참고 이미지의 광택을 그대로 따라가기보다는 원화의 의상 색과 재질 구분을 참고했습니다.

## 파일

- `Heroine_Tripo_Corrected.blend`: 수정 가능한 Blender 파일. 보정 텍스처 포함, 검토용 조명과 카메라 포함.
- `Heroine_Tripo_Corrected.fbx`: 본체와 진주 팔찌의 정적 메시. 텍스처 포함.
- `textures/`: 원본 JPG 사본과 보정한 4096×4096 베이스 컬러 PNG.
- `renders/`: 정면, 측면, 후면, 사선, 얼굴 렌더 및 전후 비교.
- `correction_stats.json`, `validation.json`: 보정 통계와 실제 FBX 재수입 검증 결과.

## 변경 사항

- 머리카락, 가디건, 피부, 치마, 스타킹, 신발, 리본, 셔츠, 눈, 기타 장식을 재질로 구분하고 반사와 거칠기를 조정했습니다.
- 머리카락과 리본의 일부 살색 얼룩을 영역별로 제한해 보정하고 기존 UV에 베이스 컬러를 베이크했습니다.
- 가디건 하단의 여유 있는 실루엣을 소폭 보완했습니다. 기존 메시의 최대 정점 이동은 약 0.002622 모델 단위입니다(원본 키 약 1 단위).
- 입꼬리와 볼·턱의 일부 내부 정점을 미세 조정했습니다. 얼굴 전체를 다시 조형한 것은 아닙니다.
- 눈 아래의 작은 분리 조각 7개(118면)와 극소 면적 면 9개를 제거했습니다.
- 원화의 캐릭터 오른쪽 손목에 진주 팔찌를 추가했습니다.

원본은 51,898 삼각형입니다. 보정 본체는 51,764 삼각형, 팔찌 포함 총 **54,116 삼각형**입니다. 약 7만이라는 예산에 맞추기 위한 불필요한 분할은 하지 않았습니다. 총 재질 슬롯은 11개이며 최적화 이전 편집용 구성입니다.

## 검증과 남은 범위

원본 ZIP과 추출된 FBX/JPG의 해시를 비교하고, 보정 FBX를 Blender에 다시 불러와 삼각형 수·UV·텍스처 로딩을 검사했습니다. 유지된 본체 면의 UV 좌표는 원본과 일치합니다.

이 파일은 1차 외형 보정본입니다. 일부 헤어 끝과 의상 경계의 UV 색 번짐, 생성 메시의 손·신발 형태 및 토폴로지는 추가 조형 작업이 남아 있습니다. 리깅·스키닝·표정 셰이프키·애니메이션 변형 검증·Unreal 재질 설정은 포함하지 않았습니다. 원본의 정규화된 크기를 유지했으므로 실제 게임 적용 시 키와 스켈레톤 기준을 맞춰야 합니다.

원본 프로젝트 캐릭터 에셋을 교체하지 않았습니다. 재현용 스크립트는 상위 폴더의 `correct_model.py`와 `validate_correction.py`에 있습니다.
