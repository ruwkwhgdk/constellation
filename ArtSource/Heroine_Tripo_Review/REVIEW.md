# Tripo 원본 검토

제공 ZIP을 별도 source 폴더로 추출했습니다. 원본 FBX의 메시·UV·텍스처·회전은 수정하지 않았습니다. `Tripo_Source_Inspection.blend`에는 원본과 검토용 조명·카메라, 패킹된 텍스처가 들어 있습니다.

## 확인 결과

- 정점 26,493 / 삼각형 51,898
- 메시 1개, 머티리얼 1개, UV 레이어 1개
- 4096 × 4096 베이스컬러 JPG 1장
- 스켈레톤·스킨 웨이트 없음
- 연결되지 않은 메시 조각 45개
- 열린 경계 엣지 1,442개, 비매니폴드 엣지 1,651개(열린 경계 포함), 면적 1e-12 미만 면 10개

경계 수만으로 결함 수를 판단할 수 없습니다. 헤어·눈꺼풀·옷 안쪽 등 의도된 열린 표면과 실제 찢어진 부분을 구분해야 합니다. 일괄 구멍 메우기·리메시는 하지 않았습니다.

가져온 모델은 의존성 그래프 갱신 후 정상적인 Z-up 방향임을 확인했습니다. 검토 파일은 가져온 원본 변환을 그대로 사용합니다. 세로 길이 약 1 Blender 단위는 정규화된 생성 모델 크기이며, 실제 키로 간주하지 않습니다.

## 시각적 판단

얼굴 인상, 비대칭 단발, 카디건과 리본, 체크 스커트의 형태가 이전 절차적 초안보다 원화에 가깝습니다. 이 형상과 텍스처를 보존하는 방향이 적절합니다.

확대 렌더에서는 눈꺼풀·볼·헤어 경계의 불규칙한 가는 조각, 헤어 끝과 리본 끝의 피부색/의상색 번짐이 보입니다. 이 중 실제 겹침·구멍과 텍스처에 그려진 흔적은 해당 면의 UV·연결 상태를 확인해 구분해야 합니다.

현재 표면 광택이 강합니다. 제공 파일에는 별도 러프니스·노멀 이미지가 없으며, 베이스컬러의 명암과 Blender 조명이 함께 결과에 영향을 줍니다. 기존 색을 유지한 재질 조정부터 비교해야 합니다.

## 보정 우선순위

1. 얼굴·헤어 근접 부위의 연결 구조와 UV를 조사하고, 원본 대비 실루엣을 유지하며 국소 보정.
2. 피부·헤어·의상·신발의 재질 반응 구분. 원본 베이스컬러 보존.
3. 손과 관절 주변을 확대 확인하고 리깅에 방해되는 접합만 정리.
4. 실제 캐릭터 크기와 기존 스켈레톤에 정렬한 뒤 웨이트 적용·변형 검증.
5. 필요한 추가 형상에 면 수를 사용. 현재 51,898 삼각형을 7만으로 억지로 늘리거나 먼저 감면하지 않음.

이 검토에서 모델 보정이나 리깅은 수행하지 않았습니다. `renders`의 이미지들은 제공된 모델 자체를 Blender 조명 아래에서 렌더한 기준 이미지입니다.
