# Heroine 추가 보정본

원화의 붉은 눈과 비대칭 헤어를 참고한 외형 보정입니다.

- 불규칙한 기존 눈 표면을 흰자·홍채의 연속된 곡면으로 교체했습니다.
- 아래 눈꺼풀의 얇은 윤곽과 피부 연결부를 추가했습니다. 양쪽 눈에 적용했습니다.
- 붉은 홍채, 동공, 작은 하이라이트를 담은 새 512×512 텍스처를 제작했습니다. 원본 홍채 텍스처와는 표현 차이가 있습니다.
- 손과 신발의 내부 정점 및 아래쪽 헤어 끝을 제한적으로 평활화했습니다. 손가락이나 신발 구조를 전면 재제작하지는 않았습니다.
- 신규 눈 표면의 노멀 방향을 정리했습니다.

총 61,038 삼각형, 메시 오브젝트 10개입니다. FBX 재수입에서 삼각형 수 일치, UV 존재, 이미지 로딩, 유효 좌표를 확인했습니다. 검증 결과는 validation.json에 있습니다.

BLEND와 FBX 모두 텍스처를 포함합니다. 리깅과 표정 변형 검증은 포함하지 않습니다. 눈꺼풀 상단과 헤어·리본의 기존 텍스처 경계에는 추가 정리가 필요한 부분이 남아 있습니다. 원본 및 이전 보정본은 별도로 유지했습니다.
