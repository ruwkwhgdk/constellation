# 눈 돌출·어깨 실루엣 보정

직전 ShoulderRefined 버전에서 지적된 눈 바깥쪽 돌출과 넓은 어깨/위팔 실루엣을 보정했습니다. 이전 결과물은 별도 폴더에 보존했습니다.

- **눈:** 흰자·홍채·눈꺼풀·주변 얼굴에 일관된 깊이 압축을 적용해 바깥쪽이 얼굴 곡면에 가까워지도록 했습니다. 정면 기준 눈 부품의 가로/세로 좌표와 기존 홍채·눈썹·속눈썹 텍스처는 유지했습니다. 정면, 양쪽 사선, 측면 렌더로 확인했습니다.
- **어깨:** 관절 간격을 직전 약 27.2cm에서 약 24.3cm로 추가 축소했습니다. 직전보다 어깨를 약 0.64cm 더 낮추고, 위팔 소매의 두께도 국소적으로 줄였습니다. 손과 팔의 길이는 유지하며 위치를 안쪽으로 조정했습니다.
- **보존:** 머리카락, 입의 무표정, 하체, 가디건 허리·밑단 좌표를 유지했습니다. UV·면 구성·재질 지정·패킹 텍스처는 기존과 동일합니다. 보호된 몸통 정점 17,584개를 수치 비교했습니다.
- **리깅:** 수정 체형에 맞춰 컨트롤/변형 뼈와 웨이트를 재구성했습니다. 160cm, 게임용 뼈 94개, 70,030삼각형을 유지했습니다.

## 파일

`Heroine_AnimationRig.blend`는 조작용, `Heroine_GameSkeleton.blend`와 `Heroine_Skeletal.fbx`는 +X 전방/+Z 위의 게임용입니다. `export_game_rig.py`는 애니메이션을 게임용 뼈에 베이크하는 기존 도구입니다. 매핑과 게임용 blend를 같은 폴더에 유지해야 합니다.

`renders/relaxed.png`는 기존과 같은 카메라·팔 자세의 비교용 전신 렌더입니다. `eye_front`, `eye_far`, `eye_oblique`, `eye_side`는 눈 깊이 검사용입니다. `bend`, `squat`는 관절 변형 검사입니다.

## 확인 범위

기존과 동일한 IK/FK 구성입니다. Pose Mode에서 `upper_arm_parent.L/R`, `thigh_parent.L/R`의 `IK_FK`는 0=IK, 1=FK입니다. Rigify UI를 사용하려면 포함된 생성 스크립트를 해당 파일에서 실행해야 합니다. 조작용 리그의 균일 스케일은 임의로 Apply하지 말고 제공 exporter를 사용하세요.

웨이트, 양손·양발 IK, 게임용 뼈 자세 전달, FBX 베이크 왕복, 원본 보존 범위, 별도 UE 5.8 프로젝트 임포트를 검증했습니다. 결과는 각 validation JSON에 있습니다. 현재 Constellation의 게임 코드와 Content 에셋은 교체하지 않았습니다.

이전 리깅본과 마찬가지로 표정 리깅, 런타임 의상/머리카락 물리, 격한 동작 전 범위의 충돌 보정, 기존 ABP 연결은 후속 작업입니다. UE Interchange의 바인드 행렬 경고가 남을 수 있으므로 실제 프로젝트에 애니메이션을 연결할 때 기준 포즈와 재생 결과를 함께 확인해야 합니다.
