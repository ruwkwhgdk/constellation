점프 능력 획득 이벤트 — 스토리보드 v01 / 2026-10-18
상태: 이미지 생성 기반 연출 제안. 실제 Unreal 렌더 또는 구현 완료 화면이 아님.
범위: 캐릭터 행동/카메라/전환 설계. 게임 에셋과 연출 그래프는 변경하지 않음.

구성: 핵심 프레임 8장, 검토용 콘티 시트 1장. 8개의 독립 컷 전환이 아님.
감정: 경계 → 호기심 → 조심스러운 접촉 → 놀람 → 감당하기 어려운 흡수 → 당황.
공간: 사용자 이미지의 폐교 방, 나무 바닥, 후방 책걸상, 별 주변 정지된 해골 소품 유지.
캐릭터: heroine_illust.png의 단발, 보라색 핀, 베이지 카디건, 남색 리본, 체크 치마 유지.
이미지는 구도와 감정의 시안이며 손의 좌우, 해골 수/정확한 위치, 치수는 구현 때 실제 배치에 고정한다.

카메라 기준
좌측 45도 = 주인공의 진행/별을 보는 방향 기준 왼쪽 앞 45도. 얼굴과 별을 함께 볼 수 있는 위치.
A: 무릎 위 또는 허리 위 미디엄, 약 12도 하향. 주인공 화면 왼쪽, 별 오른쪽. 시작 FOV 약 45~50도 제안.
B: 손과 별 접촉 인서트, 같은 시선축 유지. FOV 약 30~35도 제안.
C: 얼굴 3/4 클로즈업에서 상체 미디엄으로 완만하게 후퇴. FOV 약 40~45도 제안.
D: UI 이후 A와 같은 방향의 미디엄. 마지막에 실제 플레이 카메라로 보간.
수치는 월드 배치와 실제 캐릭터 크기 확인 후 검증할 초깃값이다. 광각 얼굴 왜곡/축 반전/전신 회전은 피한다.

01 / 2.0초 / A
컨트롤 잠금, 기존 플레이 시점에서 약 0.7초 동안 왼쪽 앞 45도 구도로 연결.
주인공과 별, 주변 해골을 함께 보여준다. 몸은 별을 향하고 양손은 몸 가까이 둔다.
02 / 2.0초 / A 연속
느린 전진. 주인공이 고개를 조금 기울여 별을 살펴본다. 웃거나 바로 손대지 않는다.
03 / 2.5초 / A 연속
오른손을 천천히 뻗고 별에 닿기 3~5cm 전에 약 0.4초 망설인다. 왼손은 몸 가까이에 유지.
04 / 1.0초 / B
손끝 접촉 인서트. 작은 빛 고리가 생긴 뒤 별이 반응한다. 접촉보다 효과가 먼저 나오지 않게 동기화.
05 / 1.2초 / C
얼굴과 어깨 반응. 눈이 커지고 숨을 멈추며 손과 어깨를 작게 뒤로 당긴다. 과한 도약/후퇴 없음.
06 / 2.0초 / C 연속
카메라가 상체 미디엄까지 살짝 후퇴. 별 형상이 가장자리부터 풀리며 빛의 흐름이 별→가슴으로 이동.
별이 몸에 들어가는 방향을 명확히 보여준 후 화면을 흰색으로 가득 채운다. 시작부터 얼굴을 가리지 않는다.
전환 / 약 1.0초
흰색 페이드 아웃 → 기존 별 능력 UI가 드러나도록 페이드 인. 기존 대사를 기존 UI 흐름으로 표시.
UI 체류: 읽기와 사용자 입력에 따라 가변. 아무 입력이나 받은 뒤 UI를 흰색으로 덮고 게임 화면으로 복귀.
전환 / 약 1.2초
화이트 덮임 약 0.4초 → 게임 화면 드러남 약 0.8초. 컨트롤 잠금 계속 유지.
07 / 2.0초 / D
별이 사라진 공간. 주인공이 가슴을 짚고 아래를 내려다본다. 잔광이 사라지고 방의 평상 조명으로 복귀.
08 / 3.0초 / D 연속
오른손바닥을 들어 확인 → 빈 별 자리로 시선 이동 → 손을 어정쩡하게 내림. 승리 포즈/점프 시연 없음.
나레이션: 알 수 없는 힘을 받은 당신은 점프 능력을 획득하였습니다.
대사 종료 후 실제 플레이 카메라로 약 1초 보간, 컨트롤 복구, 점프 안내 토스트.

구현 전 확인사항
- 별 액터와 현재 상호작용/점프 해금 로직의 실제 참조 확인.
- 기존 능력 UI의 표시/입력 종료 이벤트를 재사용하며 UI를 재구현하지 않음.
- 능력 지급과 별 소모는 일회성으로 묶고 저장/재진입/중단 처리 확인.
- 입력 잠금은 UI 선택 입력을 막지 않도록 게임플레이 입력과 구분.
- 별 소모 위치/상체 흡수 타깃을 캐릭터 상대 좌표로 설정.
- 접촉, 놀람, 흡수, 당황 포즈에 필요한 애니메이션/손 IK/시선 기능은 별도 제작 범위 확인.
- 모델/리깅 작업이 필요하면 사용자 지정 .blend와 현행 캐릭터 워크플로 확인 후 진행.
- 실제 적용 카메라는 Unreal 영상으로 검토 후 확정.
