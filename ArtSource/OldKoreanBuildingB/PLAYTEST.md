# 블록아웃 플레이 테스트

## Unreal 에셋
- 콘텐츠 폴더: `/Game/Environment/OldKoreanBuildingB/Blockout`
- 개별 메시: 하위 `Meshes` 폴더
- 조립 블루프린트: `BP_OldKoreanBuildingB_Blockout`

블루프린트를 테스트할 레벨에 끌어 놓으면 건물 전체가 배치됩니다. 액터 Scale은 `(1, 1, 1)`을 사용합니다. 액터 원점의 Z가 1층 바닥 높이입니다. 내부에 기존 지형이나 다른 메시가 겹치지 않게 배치하세요. 복도와 계단이 어두우면 테스트용 조명을 추가하세요.

## 확인할 동선
1. 1층 정면 문 → 전면 방 → 복도.
2. 왼쪽 측면 문 → 계단실.
3. 계단을 통해 2층 → 3층 → 옥상까지 이동한 뒤 역방향으로 내려오기.
4. 각 층 전면 방과 후면 방 출입.
5. 문턱·계단참에서 방향 전환, 벽 가까이에서 카메라 회전.

## 피드백에 포함하면 좋은 정보
- 층과 위치, 이동 방향.
- 걸림·낙하·카메라 확대/가림 등 현상.
- 걷기/달리기/점프 중 어느 상황인지.
- 공간이 좁거나 넓다고 느끼는 위치.

이번 단계는 단순 충돌과 공간 검토용입니다. 상세 텍스처, 소품, 문 상호작용은 플레이 테스트 피드백 이후 진행합니다.
