# v007 · 석재 색면과 식생 표면

## 유지 작업본

- 레벨: `/Game/Environment/OvergrownHall/TripoFull/Maps/L_OvergrownHall_TripoFull`
- 비교: `review.html`; 현재 실제 Unreal 촬영: `unreal_pigment.png`.
- 기존 532배치와 추가 식생53배치, 총585개 재질 오버라이드. 21종 IllustratedMaterials. v005의 정리된 메시, v006의 덩굴 배치와 최종 반사 수면 유지.

## 변경 내용

- 생성한 회화풍 광물질 표면 `Textures/painted_mineral.png`를 기둥·벽·아치·보·바닥·지붕 등10종에 사용. 원본1254px, Unreal 빌드1024px 및 평균 밉맵. 생성 경로·정확한 프롬프트는 `TEXTURE_SOURCE.md`.
- 월드 좌표 3방향 투영과 기하 노멀 가중치로 UV 섬별로 늘어나던 표면 크기를 통일. 건축330cm, 바닥240cm 반복. 청회색 광물질 바탕과 밝은 도장 박리 무늬.
- 이끼의 상부 기본 밀도를 줄이고 낮은 표면·위로 향한 턱에 집중. 마스크는 여전히 절차적이며 수작업 배치한 완성 오염 마스크는 아님.
- 식생4종의 원본 UV와 색 텍스처 유지. 밉 편향2.5, 녹색 선택 마스크를 이용한 잎색 정리와 명암 범위 축소. 나무의 갈색 줄기까지 단색 초록으로 덮지 않음. 0.075배의 작은 발광 성분으로 잎 암부 보조; 실제 광산란 모델은 아님.
- 미세 노멀을 추가하지 않아 v005의 직선 모서리 유지. 카메라·조명·배치·물·비둘기 애니메이션 수정 없음.

## 재적용

1. 유지 v006 맵 이후 `Content/Python/paint_hall_surfaces.py` 실행. 기존 파이프라인 전체를 처음부터 다시 돌릴 필요 없음.
2. `capture_hall_pigment.py`: 저장 맵 재로드, 메시532·재질585·추가식생53·물반사·충돌·비둘기 검사와 실제 렌더. `verification.json`, `exposure_render_verification.json`, 해당 실행 로그 확인.
3. `finalize_hall_pigment_texture.py`는 초기 반입 후 압축/스트리밍 속성을 정리할 때 쓴 보조 스크립트. 현재 제작 스크립트에는 동일 설정이 포함됨.
4. v004/v005/v006의 재질 적용 스크립트를 이후에 단독 실행하면 이전 표현으로 되돌아감. 최신 유지 검사는 v007 전용 스크립트를 사용.

## 남은 차이

원화의 방향성 있는 청록 음영·따뜻한 역광·밝은 외부 배경은 조명/배경 보정이 필요하다. 수목의 뾰족한 잎과 반복적인 가지는 메시·실루엣 문제도 있으므로 텍스처만으로 해결했다고 보지 않는다. 큰 식생 덩어리, 전경 수면의 원화식 반사 형태도 후속 과제다. 물은 v006과 같은 불투명 평면 반사이며 투과·물결 애니메이션 없음. 직접 플레이와 성능 측정은 미실시.

## 검증 구분

동일 카메라의 Unreal SM6 렌더와 저장된 애셋 검사를 근거로 한다. 원화 일치도에 대한 사용자 채택은 별도이며, 렌더 검사를 플레이/성능 통과로 간주하지 않는다.
