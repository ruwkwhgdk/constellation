# v011 · 수면 잔물결과 선택적 아치 파손

유지 레벨: `/Game/Environment/OvergrownHall/TripoFull/Maps/L_OvergrownHall_TripoFull`.

## 변경

- 수면: 기존 윤곽과 높이(2.2cm)를 유지하고 UV가 있는 12,640삼각형 메시로 교체. 두 방향의 느린 파동으로 최대 ±0.12cm 변위, 월드 공간 노멀로 반사 왜곡. 저주파 색 변화와 거칠기로 균일한 거울 느낌 완화.
- 파손: 채택된 v005 Tripo 보정 아치를 기반으로 두 가지 큰 결손 변형 제작. 전체 8개 중 우측 두 곳·좌측 한 곳만 교체. 작은 구멍/공중 조각이 남지 않도록 윤곽까지 열린 결손으로 수정. 각 변형은 1,370 / 1,394삼각형, 열린 경계 및 비매니폴드 모서리 0.
- 유지: v010 잎 카드 나무19·관목85·수관54, 배치·카메라·조명, 비둘기28, 기존 바닥과 보행 스케일.

## 재현

현재 v010 이후 유지 맵에 순서대로 실행한다.

1. 프로젝트 `tools/run-blender.ps1 -b -P ArtSource/OvergrownHall/Scripts/build_water_ruins.py`.
2. Unreal 전체 에디터에서 `Content/Python/apply_water_ruins.py`.
3. 별도 새 에디터에서 `Content/Python/capture_water_ruins.py`로 저장 내용 검사 및 두 시점 촬영.

Blender 프로필 보호 검사가 실패하면 정상 사용자 실행 승인을 사용한다. 가드를 우회하지 않는다. 사용자 에디터가 맵을 열고 있으면 저장 충돌을 확인한다. 예전 장면 생성/재질 스크립트는 최신 식생·물·파손을 덮어쓸 수 있으므로 단독으로 다시 실행하지 않는다.

## 증거와 한계

최종 새 프로세스 검증: 2026-09-29 00:00 KST. `Saved/HallWaterRuinsVerified.log`에서 저장 검사 통과·두 이미지 촬영·정상 종료를 확인했으며 Error/Traceback/재질 컴파일 실패 없음. 촬영은 00:00:24와 00:00:34. `temporal_comparison.json`에 수면/건축 영역의 시간차 픽셀 변화 기록(시간적 AA 차이도 포함되므로 물리 검증으로 사용하지 않음).

- `assets.json`: 실제 메시 치수·삼각형·닫힌 단면 검사. 수면의 열린 외곽160개는 의도적인 한 겹 표면이다.
- `verification.json`: 저장 맵, 파손 메시와 충돌 방식, 수면 위치와 NoCollision, 기존 식생과 새 재질, 비둘기 수 검사.
- `unreal_water_ruins.png` / `water_later.png`: 같은 카메라에서 시간차 실제 Unreal 렌더. 재질 노드만으로 애니메이션 검증을 대신하지 않는다.
- 물은 **불투명 반사 기반 미술 표현**이며 실제 수중 바닥 투과·굴절은 구현하지 않았다. 물리적 얕은 물의 최종 구현으로 간주하지 않는다.
- 평면 반사는 작은 수면 변위에 대한 근사이다. 높이 변위와 노멀 강도는 미술적으로 독립 조정했다.
- 플레이 이동, 프레임 시간, 마스크 식생 오버드로, 다른 시점에서의 반사는 별도 검증 대상이다.

다음 큰 차이는 원화의 밝고 투명한 얕은 물, 더 불규칙한 침수 경계, 후면 창 주변의 큰 벽체 결손과 국소적인 명암이다.
