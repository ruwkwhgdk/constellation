# v013 · 후면 파손·조명·식생 접합·물가 통합 보정

유지 레벨: `/Game/Environment/OvergrownHall/TripoFull/Maps/L_OvergrownHall_TripoFull`.
사용자가 플레이 테스트를 직접 담당하기로 했다. 이번 작업에서는 플레이를 실행하지 않는다.

## 반영

1. **후면 건축**: 승인된 v005 Tripo 보정 소스에서 닫힌 파손 변형4종 제작. 후면 벽3·하부 창틀3·아치 창틀1·보3, 총10곳 교체. 반복 전체를 무너뜨리지 않고 양쪽과 일부 중간 부재에 집중. 삼각형은 벽488·창틀680·아치창1104·보84, 비매니폴드/열린 경계0.
2. **조명/색**: 태양 방향−55°와 노출1024 유지. 태양17500, 청록 하늘 보조광1.35, 후면 면광원200000. 벤치 앞 수면을 향하는 따뜻한 보조 스포트1개(300000cd, 외각27°, 내부12°, 반경1600cm), 전체 대비/색감 조정. 보조광은 원화 연출을 위한 미술 조명이며 실제 건축 조명 기구가 아니다.
3. **식생 접합**: 후면 파손·벽/보 접합에 국소 습윤 이끼 영역4개 추가. 기존 비대칭 이끼 패턴을 유지한 별도 재질2개. Tripo 덩굴9개를 접점에서 아래로 늘어뜨리고 회화풍 잎 군집5개 추가. 균일하게 벽 전체를 덮지 않는다.
4. **물가**: 낮은 파손 석판9개와 일부 잠긴 Tripo 잔해6개를 가장자리에 배치. 중앙 동선과 아래쪽 바닥을 유지. 작은 장식은 NoCollision.

기존 v010 식생, v011 측면 아치 파손3곳, v012 투명 수면·잔물결·침수바닥47개 높이, 비둘기28 유지. 형태 검증과 실제 이동 검증은 별개다.

## 재현

1. `tools/run-blender.ps1 -b -P ArtSource/OvergrownHall/Scripts/build_hall_final_details.py`.
2. 전체 Unreal 에디터에서 `Content/Python/finish_hall_art.py`.
3. 새 에디터에서 `Content/Python/capture_hall_final_art.py`.

적용 스크립트는 이 단계의 `OH_Finish_` 장식과 광원만 다시 생성한다. 나머지 승인 애셋을 지우지 않는다. 변경 전 모듈 메시/재질은 `baseline.json`에 기록했다. 기존 Graph·월드 투영·비대칭 이끼 제작 함수는 v006/v007/v008 Python 소스의 순수 제작 부분을 재사용하므로 해당 소스를 보존한다. 이전 단계 전체 적용 스크립트를 단독 재실행하면 최신 수정이 되돌아갈 수 있다.

## 검증

- `assets.json`: Blender 실제 폴리곤, 치수, 닫힌 파손 단면.
- `verification.json`: 저장 맵의 교체·추가 개수, 충돌 설정, 기존 식생/물/바닥/비둘기 보존.
- `unreal_final_art.png`: 고정 카메라의 실제 Unreal 렌더.
- 고정 카메라에서 시작/셰이더 준비 후 20초 CSV를 수집한다. 에디터 창·UI·백그라운드 상태의 비용을 포함하므로 게임 FPS 또는 플레이 성능 보증으로 취급하지 않는다.

최종 검증: 2026-09-29 00:48 KST, `Saved/HallFinalArtActiveVerify.log`. 저장 검사·실제 렌더·정상 종료 확인, Error/Traceback/재질 컴파일 실패 없음. 처음 CSV는 장면이 갱신되지 않는 대기 구간이라 폐기하고, viewport invalidate를 사용해 다시 측정했다.

`performance.json`: 실제 Basepass가 있는 753프레임만 집계. GPU 중앙값12.65ms / p95 13.23ms, 에디터 프레임 중앙값25.58ms / p95 33.22ms. RHI 호출 중앙값1100, 그중 그림자 패스 호출577. 창 요청 크기는1200×640이며 UI를 제외한 뷰포트 해상도와 게임 해상도는 다를 수 있다. 최적화 전후 개선 수치로 해석하지 않는다. 향후 성능 보정에서는 그림자 비용과 식생 LOD/마스크 오버드로를 우선 조사할 근거로 남긴다. 원본은 `Saved/Profiling/CSV/Hall_v013.csv`, 재집계는 일반 Python으로 `ArtSource/OvergrownHall/Scripts/summarize_hall_profile.py` 실행.

## 사용자 확인과 남은 범위

직접 플레이의 이동·카메라·다른 시점에서의 체감은 사용자 담당. 물리적 물 굴절/수중 모델과 캐릭터 파문, 식생 바람 애니메이션/LOD는 이번 미술 보정 범위 밖이다. 원화는 단일 회화 이미지이므로 현재 결과를 완전 일치로 판단하지 않는다.
