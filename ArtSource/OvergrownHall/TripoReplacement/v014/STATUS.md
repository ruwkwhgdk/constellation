# v014 · 식생 바람·거리 LOD·반사/그림자 비용 조정

유지 맵: `/Game/Environment/OvergrownHall/TripoFull/Maps/L_OvergrownHall_TripoFull`.
사용자가 직접 플레이를 담당하므로 PIE 또는 게임 이동 테스트는 실행하지 않는다.

## 변경

- 나무19·관목85·수관59, 총163개에 별도 Runtime 메시/잎 재질 적용. 가까운 LOD0와 원래 줄기 재질, 배치, 나무 충돌을 보존.
- 잎 슬롯에만 위치/시간 기반의 미세 바람 적용. Y축 최대 변위는 근경0.92cm, 원경0.46cm이고 X/Z는 그보다 작다. 줄기와 충돌은 움직이지 않는다. 머티리얼 시간 애니메이션이며 물리 시뮬레이션은 아니다.
- 3단계 LOD 삼각형: 나무17103/10261/5131, 관목6157/3695/1848, 수관8736/5242/2620. 가까운 실루엣 보존을 우선하며 관목은 더 작은 화면 크기에서 전환.
- 접합 잎·작은 덩굴·먼 수관36개의 그림자와 미술용 초점 보조광의 중복 그림자 제거. 태양과 주요 나무 그림자는 유지.
- 수면 평면 반사 해상도75→60%. 매 프레임 갱신은 유지하며 물의 투명도·잔물결·재질은 변경하지 않는다.

## 재현과 검증

1. v013 유지 맵에서 `Content/Python/refine_hall_foliage_runtime.py` 적용.
2. 새 Unreal 프로세스에서 `Content/Python/capture_hall_runtime.py`로 저장 상태 검사 및 실제 렌더.
3. 일반 Python으로 `ArtSource/OvergrownHall/Scripts/summarize_hall_runtime.py`를 실행하여 CSV 집계.

원본 메시/재질은 유지하고 `/TripoFull/FoliageRuntime`에 파생본을 저장한다. `baseline.json`은 누적 적용을 방지하는 원배치·재질·그림자 입력이므로 보존한다. `wind_graphs_created.json`은 재질 그래프 중복 생성을 방지한다. 이전 v010/v013 전체 적용은 최신 메시/그림자를 되돌릴 수 있으므로 단독 재실행하지 않는다.

`verification.json`은 저장 맵의 LOD/잎 슬롯/위치/충돌/기존 건축·수면·비둘기 보존 검사다. `unreal_runtime.png`는 실제 고정 카메라 렌더다. 바람의 플레이 중 체감, 이동 시 LOD 전환, 충돌/카메라는 사용자 플레이 확인 대상으로 남긴다.

## 성능 해석

고정 카메라 에디터 강제 갱신 구간에서 Basepass가 있는 프레임만 집계한다. CSV의 footer/event 메타데이터는 제외한다. 창 요청 크기1200×640과 실제 뷰포트 크기는 다를 수 있다. 별도 프로세스 측정이며 게임 FPS 또는 모든 시점의 성능을 보증하지 않는다.

최초 바람/LOD 적용은 GPU12.65→14.02ms로 악화되어 최적화 성공으로 취급하지 않았다. `performance_first_trial.json`과 `performance_shadow_trial.json`에 중간 측정을 남긴다. 최종 수치는 `performance.json`, v013 비교는 `performance_comparison.json`을 참조한다. 호출/삼각형 감소만으로 GPU 개선을 주장하지 않는다.

최종 별도 프로세스 검사: `Saved/HallRuntimeVerify.log`, 2026-09-29 01:07 KST. 저장본 검사 통과, 실제1200×640 촬영 확인. 실제 렌더771프레임의 GPU 중앙값12.69ms/p95 13.01ms로 v013의12.65ms와 사실상 비슷하다. RHI 호출1100→961(−12.6%), 그림자 호출577→434(−24.8%), 전체 패스 삼각형 약1840만→1658만(−9.9%). 에디터 프레임 중앙값25.58→23.81ms. 바람 기능 추가와 거리별 삼각형 절감은 확인했으나 GPU 속도 향상으로 결론내리지 않는다.

남은 범위: 사용자 플레이 확인, 목표 플랫폼별 실제 게임 프로파일링. 물리 굴절·수중 모델·캐릭터 파문은 별도 기능이며 이번에 구현하지 않았다. 원화와의 완전 일치를 의미하지 않는다.
