# v016 · 원화 비교 후 통합 미술 보정

유지 맵: `/Game/Environment/OvergrownHall/TripoFull/Maps/L_OvergrownHall_TripoFull`.
사용자가 승인한 순서: 창밖 배경 → 조명 → 식생 → 수면 → 건축 → 비둘기.

## 변경

1. **정면 원경**: 후면 나무를 복구하지 않고, 홀 밖 Y=60m에 연녹색–크림색의 흐릿한 색 원경을 추가. 월드 높이와 저주파 노이즈로 색을 변화시킨다. 이는 미술용 배경이며 실제 숲 모델/산란 시뮬레이션이 아니다. 충돌/그림자 없음.
2. **빛**: 노출1024와 카메라 유지. 태양15500, 광원 각도18°. 기존 따뜻한 초점 스포트850000cd, 내부10°/외부23°, 광원 반경95cm, 볼류메트릭 계수1.1. 새 전역 노출 상승 없이 벤치 앞 초점을 보강. 원경 emissive 배율1100, 비둘기250은 이 고정 노출용 미술 값으로 다른 노출에 그대로 복사하지 않는다.
3. **식생**: 관목85개의 높이·폭·위치·간격을 v015 기준에서 비균일하게 조절. 벽/기둥에 납작한 잎 군집13개를 국소 배치하고 기존 가는 덩굴에 약한 녹색 밝기 보조를 적용. 남은 나무/관목 Runtime LOD·잎 바람 유지.
4. **수면**: 기존 잔물결/노멀을 보존하는 별도 재질. 저주파 마스크로 roughness0.055–0.16, 정면 불투명도0.74–0.88을 변화시키고 비스듬한 시선에서는0.95. DepthFade14cm. 평면 반사 prefilter roughness0.075, normal distortion0.45. 수면 가장자리에 작은 파손 석판6개 추가. 물리 굴절/접촉 파문은 별도.
5. **건축**: 천장50배치의 푸른 회색 무광 재질, 기둥/주두/아치01–04의 넓은 광물 색면·박리 무늬·큰 이끼 패턴. 기존 형태와 닫힌 천장 유지.
6. **비둘기**: 기존 Tripo 리깅과 Fly/Glide 전환 클립 유지, 28마리 비행 범위를 더 넓게 분산. 기본높이350–890cm 및 작은 상하변위, 스케일0.50–0.66. 원 텍스처에 따뜻한 색과 미술용 밝기 보조를 혼합. 반복20초/48fps 유지. 경로 표본의 중심간 최소거리 검사는 날개 충돌/동적 회피 보증이 아님.

## 소스와 재현

`Content/Python/refine_hall_painterly_finish.py` 적용 → `capture_hall_painterly_finish.py` 저장본 확인/실제 촬영. `baseline.json`은 v015 정적 메시 배치를 보존하고 관목 재적용의 누적 변형을 방지한다. 기존 원본 메시/텍스처는 유지하며 `/TripoFull/PainterlyFinish`의 파생 재질을 사용한다. `OH_Painterly_` 배치는 매번 재생성한다. 비둘기 제작은 기존 `build_overgrown_flock.py`의 리깅/클립 처리와 Sequencer 경로 생성 방식에 새 경로값을 적용한다.

이전 v014/v015 적용/검사 스크립트는 최신 재질/배치를 가정하지 않으므로 단독 실행하지 않는다. v015에서 제거한 정면 나무/수관63개 기록 중 지붕18을 제외한45개 식생 배치는 계속 부재해야 한다.

`verification.json`은 추가 배치·나무 제거 유지·닫힌 천장·수면 재질·비둘기 재질/개수/경로 간격 검사, `unreal_finish.png`는 실제 Unreal 화면이다. 플레이 테스트는 사용자 담당이며 이번에 실행하지 않았다. 새로운 성능 측정은 하지 않았으므로 이전 성능 수치를 최신 결과의 성능으로 제시하지 않는다.

최종 원경의 높이 혼합은 월드Z900–3500cm 기준이다. Y60m의 원경에 닿는 카메라 광선 높이를 고려한 값이며, 창 자체의 높이와 같지 않다. `balance_hall_distant_haze.py`는 본 적용 스크립트의 같은 재질 레시피만 재실행하는 보정 도구다. 실제 씬을 여러 번 다시 생성하지 않고 원경만 조정할 수 있다.

경로 표본 최소 중심간격73.66cm. 벽/보 충돌이나 날개 상호 충돌의 플레이 검증과 구분한다. 검증 로그: `Saved/HallPainterlyPerspectiveFinal.log`. 중간의 변수 이름 충돌과 삭제된 임시 배치 참조 오류는 스코프 분리 및 액터 목록 갱신으로 수정했다. 실패한 실행을 성공 기록으로 취급하지 않는다.
