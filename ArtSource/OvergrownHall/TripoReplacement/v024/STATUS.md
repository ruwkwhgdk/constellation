# v024 · 원화의 창 구성과 벽체 비율 재검토

v023의 시각적 통과 판정을 철회하고 큰 형태부터 다시 대조했다. 같은 카메라에서 네 칸으로 반복되던 창을 큰 세 칸과 좌측 부분 창으로 바꾸고, 좁았던 층 사이 띠를 원화 비율에 맞춰 보강한다.

## 구조

- 후면 경계 X:610,477,158,−151,−498cm. 각 경계 기둥은 기존 메시·두께를 유지하고 위치만 보정.
- 아래 창 Z315–675cm, 위 창 직사각형 Z825–970cm. 아치 상부는 기존 유지. 층 사이 띠 Z675–825cm.
- 좌측 일부를 가리는 벽의 중심555cm, 폭65cm로 변경.
- 기존 측면 부러진 보4개를 중간 높이로 재배치하고 길이2.35배, 부착 잎4군집 추가. 보 바운드 최저 높이3m 초과, 중앙 통로의 구조/치수는 보존.
- 유지 Tripo 벽 소스에서 겹친 몰딩·본체를 합친 뒤 아래 가장자리를 파손한2변형 생성.최종454/462삼각형(v025 재반입), nonmanifold0. 8개 상부 벽 배치:측면 X±652, Y400/800/1200/1600, Z450–1140cm. 닫힌 천장50개 유지.
- 광원은 좁은 사선 방향:상단(−440,1850,1000)→(0,1050,0), inner7°/outer10.5°,2800000,볼류메트릭5. 전역 안개 밀도0.018로 넓은 안개광 완화.

## 재현

`Scripts/build_hall_upper_wall_infill.py`를 `tools/run-blender.ps1`로 실행한 뒤 `Content/Python/refine_hall_reference_proportions.py` 적용. 검사는 `capture_hall_reference_proportions.py`.

`baseline.json`은 v023 기록. 기존 재질/메시는 보존하며 이번 변경 범위의 배치·변형만 적용. 새 액터는 `OH_ReferenceProportion_` 접두사로 재생성. 이전 전체 스크립트 단독 실행 금지.

`landmark_projection.json`은 고정 카메라 투영과 원화의 수동 추정 기준점 일곱 곳 비교. 원화 레터박스 제외 후 비교를 가정한 근사 검사이며 자동 이미지 유사도나 픽셀 단위 일치를 뜻하지 않는다. 최대 차이 약7.1px, 허용20px. 실제 렌더를 별도 확인해야 한다.

직접 플레이/성능 테스트 미실행. 최종 시각 판정은 실제 최신 렌더 확인 후 기록한다.
