## 웹사이트 전환 시 인계

기존 승인 이미지와 Jobs의 정확한 프롬프트를 사용한다. 부품 ID 및 원화 버전을 유지하고 결과 GLB/FBX와 텍스처를 같은 ID 폴더에 보관한다. Blender 규격 보정·연결 검사를 거치지 않은 생성 결과를 바로 Unreal에 완료 처리하지 않는다. Tripo 웹 서비스의 모델 이름·과금·옵션이 API와 같다고 가정하지 않는다.
