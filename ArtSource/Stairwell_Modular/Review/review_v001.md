# 계단실 모듈러 원화 검토 v001

상태: 사용자가 보완 부품을 전부 채택했다. 기존 채택 부품과 02~04 공통 타일 규격, 09~12 보완 연결 체계, 17~22 보완 부품으로 3D 제작을 진행한다. 원화 채택과 3D 결과 승인은 별개이며 Blender 결과 검토가 남아 있다.

## 목적과 승인 범위

- 원본: `../References/source_scene.png` (사용자 첫 번째 이미지).
- 원본의 타일, 점자블록, 금속 난간, 문, 형광등과 거친 콘크리트 스타일을 유지한다.
- 사용자의 두 번째 및 세 번째 이미지는 작업 방식의 예시이며 현재 후보들의 승인 기록이 아니다.
- 현재 단계는 2D 원화 시트 제작이다. 3D 생성과 Unreal 임포트는 아직 시작하지 않는다.
- 플레이어는 BP_Player_Heroine 기준이다. 슬라임은 별도의 이동 규칙을 따르므로 제외한다.

## 확정한 초기 규격 (cm)

| 항목 | 값 |
|---|---|
| 난간 사이 유효 폭 | 120 |
| 계단 한 단 높이 / 깊이 | 15 / 30 |
| 계단 경사 | 약 26.565도 |
| 계단참 깊이 | 180 |
| 문 유효 개구부 | 100 × 210 |
| 계단 위 보·조명 아래 유효 높이 | 최소 220 |

계단 메시 폭 140cm는 양쪽 난간 돌출 영역을 각 10cm씩 확보하는 제작 초안이다. 충돌체 기준으로 유효 폭 120cm를 유지해야 하며 최종 조립에서 검증한다. 그림 속 치수나 비율은 측정 기준이 아니다. 위 규격이 우선한다.

- 02 계단참과 03 바닥은 같은 타일 체계를 사용하도록 제작한다. 별도 메시 유지 여부는 작업자 선택에 따른다.

## 후속 검증

- 사용자 선택 이후 재현 가능성 검토: `assembly_audit_v001.md`.
- 보완 작업 결과, 17~22 원화와 Blender 연결·타일 비교: `supplement_review_v001.md`. 보완 진행 승인과 결과물 최종 채택을 구분한다.
- 02/03/04 공통 타일 피치 30×30cm는 수정 제안값. 02는 180×180cm(6×6칸), 03/04는 60×60cm(2×2칸) 검토 샘플로 요청했다.
- v003 Task ID: `4acbd676-0bbd-49eb-967a-6237442fdd45`. 원본 v002를 입력으로 02/03/04만 수정 요청.
- v003 완료: `../Concepts/concept_sheet_v003.png`. 02/03/04에 공통 30×30cm 피치와 패널 크기 표기가 반영됐으며 03/04는 2×2 구성으로 표현됐다. 그림의 실제 투영 치수·줄눈 폭 정합은 보장하지 않는다. 02는 칸에 맞춰 축소 표시돼 03/04와 화면상 타일 크기가 다르다.
- v003에서 07 표면 등 승인 부품에도 부수적 외형 변화가 관찰됐다. 이 변경은 채택하지 않는다. 채택된 01,05~08,13~16은 v002 원본을 계속 기준으로 사용한다.
- v003 사용량 10크레딧. 현재까지 누적 30, 잔액 60, 예약 0 확인.
- 01,05~08,13~16의 채택 기준 이미지는 v002이다. v003에서 이 부품이 부수적으로 변해도 새 외형을 자동 승인하지 않는다.
- 09~12는 연결 질문에 대한 검토 상태이며 승인으로 간주하지 않는다.
- 추가 난간 전환부와 벽 마감 파생형은 신규 제안이다. 사용자 확인 없이 채택 처리하지 않는다.

- 시트는 외형과 분리 방식의 검토 자료이며 제작 도면이나 최종 3D 입력이 아니다.
- 선택 이후 필요한 부품은 개별 고해상도 이미지로 준비한다.
- 모듈 접합부, 삼각형 예산, UV, 재질, 피벗, 충돌은 3D 제작 단계에서 검사한다.
- 실제 플레이 중 크기 변화, 애니메이션과 카메라 간섭은 Unreal 블록아웃에서 검사한다.
