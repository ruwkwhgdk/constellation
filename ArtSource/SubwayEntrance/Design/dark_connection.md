# 어두운 통로 연결 · 승인된 방향의 실행 기록

사용자는 2026-09-30 어두운 공간을 걸어 통과하며 같은 공간으로 느끼는 연출과 스트리밍 선행 로딩을 승인했다. 존댓말로 응대한다. 플레이 확인은 사용자 담당이다.

- 두 원본 맵은 별도 유지. 같은 UWorld에 목적지를 비동기 로드하여 Pawn/Controller/GameInstance와 이동 속도·시선·카메라를 보존한다.
- 입구 하부 참에서 짧은 추가 경사와 꺾인 폐쇄 통로를 만든다. 내부 상부 참 뒤에도 대응 통로를 만든다. 화면 페이드와 OpenLevel 호출을 제거한다.
- 로드 전부터 안전 바닥과 충돌 벽을 유지한다. 준비가 늦으면 검은 통로 끝의 안전 장벽이 진행을 막되 뒤로 걸어 나올 수 있다. 활성 소스의 장벽은 유지하며, 목적지 바닥/캡슐 검사를 통과했을 때 장벽 앞에서 전환한다.
- 양쪽 전역 하늘·비한정 후처리는 점유한 레벨의 것만 활성화한다. 로컬 조명과 기존 측광 방식을 유지하는 통로 한정 노출 Bias로 어두워지는 깊이를 제어한다.
- 상대 좌표/속도/시선 회전 보존, 도착면 재진입 방지, 목적지 바닥/캡슐 검사, 왕복 인스턴스 재사용을 검사한다.
- 저장 맵 외부 변경 범위와 통로 단순 충돌을 편집기에서 확인하고 실제 렌더를 비교한다. PIE/플레이 및 패키지 성능 검증은 실행하지 않는다.

결정: 현재 두 맵은 World Partition이 없고 GameMode override가 동일(None)이다. 첫 맵을 persistent로 유지하며 목적지 인스턴스를 세션 동안 보존한다. 방문 상태와 캐릭터는 재생성하지 않는다. 비용은 두 공간의 메모리 상주이며 추후 실제 플레이 성능을 별도로 측정해야 한다.

작업 상태: 스트리밍/통로 구현, 빌드, 상태·왕복 변환 검사, 바닥 충돌 검사와 최종 저장본 6장 렌더 확인 완료. 실제 플레이는 사용자 확인 대기이며 실행하지 않았다. 유지본과 재현 순서는 ../CURRENT.md에 기록했다.
