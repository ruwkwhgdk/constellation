사용자 완료 통보된 Heroine Final03 전달 클립 8개를 연결했다.
Approach → BraceLoop(QTE 무제한 대기) → ExtractRecover → RegripRight → ReleaseLeft → Raise → RaisedHoldLoop(실제 아이템 UI 확인 대기) → Lower → 녹슨 검 획득 안내 → Combat/Attack 해금 → 카메라/조작 복구 → 공격 토스트.
공유 ItemAcquisitionSubsystem과 DA_RustySword를 사용한다. 기존 별 제거와 중복 획득 방지를 유지한다.

실행 방식
- 원본 AS/AM 및 캐릭터 모델은 수정하지 않았다. 런타임 몽타주 복사본에 루프 섹션을 설정한다.
- 검의 메시 피벗을 전달된 가드 중심 트랙에 맞추고, 몽타주 시간으로 30fps 트랙을 샘플링한다.
- QTE 성공 및 UI 확인 시 현재 2.4초 호흡 주기를 마친 후 다음 클립으로 연결한다. 최대 2.4초 전환 대기가 있을 수 있다.
- 연출 중 원본 자세 보존을 위해 캐릭터 포스트프로세스를 잠시 끄고 종료/취소 시 복구한다. 기존 ABP를 교체하지 않는다.
- 취소 시 검 컴포넌트 변환, 캐릭터/검 상태 및 기존 입력 잠금을 복원한다.
- 실제 UI에 검과 캐릭터가 가려지지 않도록 C 카메라를 옮겼다. 검 메시 원본을 변경하지 않고 인스턴스 길이만 조정해 바닥에 꽂힌 위치를 맞췄다.
