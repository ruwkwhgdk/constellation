## Unreal 구현 — 사용자 승인 반영

실제 게임 적용과 미리보기 방법은 [UNREAL.md](UNREAL.md)를 참조한다. 아래는 시안의 변경 이력이며 최신 수정이 이전 결정을 대체한다.

## 최신 수정 — 벽화 붓결 / 기존 별 문양 복원

- 미획득 공간의 불투명 검정 원형 그라데이션을 제거. 불규칙한 청흑색 드라이브러시 안료 자국으로 변경하여 원본 벽면 질감을 드러낸다.
- 메인 별자리 선/별 레이어에 0.35px 흐림을 적용. 점선은 가는 붓결 3겹, 겹별 윤곽은 옅은 어긋난 안료선으로 처리한다. 텍스트에는 흐림을 적용하지 않는다.
- 기존 별은 겹별·내부선·외곽 점·마름모가 있는 직전 상세 문양으로 복원. 단순 별 윤곽과 65% 투명도는 폐기.
- 신규 별에만 따뜻한 금빛 번짐과 밝기 효과를 추가. 알파>베타>감마 크기, 문구/좌표/획득 규칙 유지.

## 최신 수정 — 미획득 공간 / 별 크기와 표현 단계

- 검정 점선 해석을 취소하고 연결선을 금박 점선으로 복구했다.
- 미획득 슬롯의 빈 공간에 검은 중심과 부드러운 가장자리의 음영(반경 65px)을 표시한다. 새로 획득하는 위치는 점등 시 음영이 사라진다. 미획득 별 아이콘은 생성하지 않는다.
- 별 옆 그리스 문자·한글 별 이름을 모두 제거했다. 상단 α/β/γ CrB는 유지한다.
- 사용자가 지정한 밝기 순서를 시각적 크기로 반영: 알파 46px > 베타 39px > 감마 34px 기본 반경. 천문학적 광도 비율을 그대로 환산한 값은 아니다.
- 신규 별: 기존의 겹친 8각 문양, 내부 선, 외곽 점·마름모와 선명한 금빛을 유지한다.
- 기존 별: 한 겹의 8각 윤곽·중심점만 남기고, 불투명도 65% 및 얇은 선으로 낮춘다. 크기는 별의 슬롯에 종속되어 획득 순서와 무관하게 유지된다.

## 최신 수정 — 중앙 세로 공간 / 대비

- 제목 기준선 218→145, 설명 첫 줄 796→896: 사이 공간 578→751px, 약 30% 확대. 영문 상단 제목은 y=70, 안내는 y=1010.
- 별자리 좌표는 중심 y=464.5 기준으로 세로 1.3배 확대. 가로 위치와 획득 순서는 유지.
- 배경 렌더링에 1.2px 흐림, 채도 65%, 불투명도 72% 적용. 원본 배경 파일은 유지.
- 미획득 연결 구간은 불투명 검정 점선, 획득 구간은 밝은 금빛 점선으로 구분. 별 문양도 획득 상태에서만 표시.
- 중앙 별/텍스트에는 배경 흐림 필터를 적용하지 않음.

## 최신 수정 — 장식 밀도 축소 / 금박 별 문양

- mural-background-v2.png: 내장 ImageGen 편집으로 좌우 문양·고리·금박 점의 수를 약 절반 수준 목표로 줄였다. 정확한 개수 계수값이 아닌 시각적 밀도 기준이다.
- 중앙 별자리: 긴 금박 대시와 작은 점을 번갈아 배치. 획득 별은 겹친 8각 별, 내부 꽃잎/방사선, 점과 작은 마름모 장식으로 표현한다.
- 장식은 획득 별에만 붙으며 미획득 슬롯에는 별 문양을 만들지 않는다. 문양과 연결선이 겹치지 않도록 선 양 끝에 여백을 둔다.
- 별 위치·획득 순서·문구·입력 흐름은 유지한다.

# 어빌리티 획득 UI — 검토용 mockup

2026-10-09 · 1920×1080 · Unreal 적용 전 시안

`mockup.html`을 브라우저에서 열면 점프 / 전투 기술 / 변신을 비교할 수 있다. ‘연출 재생’은 임시 합성 SFX와 함께 재생한다. 연출 종료 후 아무 키나 누르거나 화면을 클릭하면 UI가 페이드 아웃된다. 실제 게임은 연결되지 않아 복귀 자리표시 화면이 나타난다.

## 디자인 기준

- 사진 2·3의 중앙 집중형 공개 연출과 제목/설명 위계를 참고한다. 프레임·문자·문양은 이 게임의 별 세계관에 맞춰 구성한다.
- 화면 1: 별 없는 검은 배경과 사진 4의 왕관 기호. 청색 발광, SFX, 문양 소멸.
- 화면 2: 남색 밤하늘, 낮은 밝기의 배경별, 중앙 북쪽왕관자리, 위쪽 제목, 아래쪽 기존 설명, 하단 Press Any Key.
- 미획득 위치에는 별·점·잠금 아이콘을 그리지 않는다. 전체 형태는 아주 흐린 연결선으로만 표시한다. 전체 연결선 표시는 이번 시안의 가정이며 검토 후 제거 가능하다.
- 기존 별은 화면 2 시작부터 별자리와 함께 나타나며, 신규 별 하나만 응축→섬광→안정으로 점등된다. 배경별은 주 별자리 경로 근처를 비워 구별한다.
- 사진 5의 좌표와 획득 순서를 기준으로 한다. 연결 순서와 획득 순서는 별도로 관리한다.

## 별 슬롯과 데이터

|---|---|---|---|---|

| 2 | β | 오른쪽 중간 | 전투 기술 | AbandonedSchool_Star_Object_Combat |

연결 순서: ι–ε–δ–γ–α–β–θ.

설명 출처: `/Game/Constellation/Gameplay/Sequences/Data/DT_SequenceStringData`, `Description` 필드. uasset에서 UTF-16 원문과 직후 로컬라이제이션 키를 읽어 매핑했다. 문자열의 리터럴 \n은 실제 줄바꿈으로 표시한다. `ST_StringData`는 행 구조체 에셋이다.

점프:
> 왕의 별은 누구보다 높은 곳에서 빛나야 한다.
> 별들이 길을 잃으면, 그들을 인도할 길잡이가 언제나 필요하기에.

전투 기술:
> 왕관은 무거우면서도 달콤하다.
> 그것을 머리에 쓴 자는, 자신을 지키기 위해 어떤 것과도 싸워야 할 준비가 되어 있다.

변신:
> 세상에서 살아남기 위해선, 그 세상에 맞는 모습으로 자신을 변화시킬 필요가 있다.
> 그리고 대부분의 별들은 그 과정에서 자신을 잃어버린다.

데이터 확인사항: 별도 `Attack` 행에는 ‘그 힘은 소중한 것들을 지키기 위해 주어졌다…’ 문구가 있다. 전투 기술은 `Combat`을 사용했다. 기존 `Name` 필드의 별 표기(Jump β, Combat δ, Metamorphosis ε)는 새 요청과 달라 시안에는 사용자 지정 α/β/γ 및 제목을 우선했다. 실제 적용 시 매핑을 확정해야 하며 원본 데이터는 수정하지 않았다.

## 작업 계획

1. **시안 검토:** 문양 크기, 별자리 배치, 글꼴·밝기, 6.2초 연출 길이를 검토한다. Combat/Attack 설명 선택, 전체 연결선 표시 여부, 기존 Name 필드와 새 별 배정 차이를 확정한다.
2. **리소스 제작:** 아래 그래픽을 분리 출력하고 실제 SFX를 제작한다. FHD/QHD 가독성을 검토한다.
3. **데이터 연결:** AbilityID, StarSlot, Title(FText), Description(FText/행 참조), AcquiredFlags[7], NewlyAcquiredSlot을 전달한다. 미정 4개 능력은 이름·기능을 임의 확정하지 않는다.
4. **UMG 구성:** WBP_AbilityAcquisition 내부에 BlackOverlay, Starfield, Emblem, ConstellationLayer(7개 독립 별), Title, Description, ContinuePrompt를 배치한다. Safe Zone과 기준 캔버스/ScaleBox를 사용한다.
5. **연출·입력:** FadeIn→Emblem→Reveal→Ignition→Text→AwaitInput→FadeOut. 대기 전 입력 및 누르고 있던 키의 반복 입력을 무시하고 새 누름만 수락한다. 게임패드도 연결한다. 브라우저 시안은 키보드·클릭만 지원한다.
6. **게임 복귀:** 기존 HUD/입력 모드/커서/일시정지 상태를 보관하고 종료 시 원상 복구한다. 게임 정지 중에도 UI 연출·사운드가 진행되도록 설정한다. 중복 획득 이벤트는 큐 또는 무시 규칙을 확정한다.
7. **검증:** 0→1, 1→2, 2→3, 임의 보유 집합에서 신규 슬롯 외 변동이 없는지 확인한다. 16:9·21:9, DPI, 긴 번역문, 키보드·패드, 메뉴 포커스, 입력 연타, 일시정지 복귀를 확인한다. 모션 감소 모드는 섬광/반복 점멸을 줄인다.
