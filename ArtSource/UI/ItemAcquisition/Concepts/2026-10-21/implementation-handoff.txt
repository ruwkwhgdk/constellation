- 모든 아이템 획득 시 자동 표시하지 않음. 이벤트 진행, 보물상자 개방 등 기획자가 명시한 특별 획득 상황에서만 호출.

- 실제 아이템 지급과 화면 표시는 분리. 재표시/취소/스킵/이벤트 재진입으로 중복 지급이나 지급 누락이 생기지 않도록 기존 지급 정책 유지.
- 별도 호출 경로 또는 기존 연출 툴과 일관된 노드로 표시하고 닫힘을 기다려 다음 연출 진행 가능하게 구성. 일반 획득 흐름을 일괄 교체하지 않음.

- 패널 내부 짙은 남색 배경과 가장자리 성운 질감은 유지. 카드 외부는 투명하여 현재 게임/컷신이 보이도록 함. QTE의 배경 제거 조건을 카드 내부까지 적용하지 말 것.
- 비교 시트의 바깥 회색 배경, PROJECT CONSTELLATION 제목, A/B 라벨은 제외. 시트 전체를 UI 텍스처로 붙이지 말고 패널/장식/아이템/텍스트를 분리.
- 왼쪽 Sprite 영역, 오른쪽 아이템 이름/가는 구분선/설명. 아이보리 명조 계열 제목과 읽기 쉬운 본문. 아이템의 원래 색상 유지; 금빛은 후광/장식 위주.
- 긴 검과 작은 열쇠처럼 서로 다른 종횡비에 대응. Sprite 비율 유지, 자르거나 늘리지 말 것. 필요하면 아이템별 표시 배율/오프셋 제공.
- 설명 2~4줄 기준, 긴 한글은 자연스럽게 줄바꿈하고 패널 높이 대응. 지나친 자동 축소나 무조건 말줄임 금지.
- 중앙보다 약간 아래 배치 제안. 시안은 확대 비교본이므로 실제 게임 화면에서 크기/여백/DPI 조정.
- 공격력/버프/등급/인벤토리 바로가기/'아이템 획득!' 대제목은 추가하지 않음.
