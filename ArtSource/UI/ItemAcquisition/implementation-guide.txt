특별 아이템 표시 UI — 기획자 연결 안내

2026-10-21 외형 수정
사용자 요청에 따라 뷰포트 정중앙 배치, 1468×390 고정 비율로 변경했다.
UI 시안 제작 채팅에서 전달한 Production/2026-10-21 전용 리소스로 배경/이중 프레임/코너 별자리/후광/구분선을 교체했다.
리소스 가져오기: tools/import-item-relic-art.py → /Game/Constellation/UI/ItemAcquisition/RelicArt.
제목과 본문 영역을 분리하여 긴 본문을 스크롤해도 제목과 카드 외형은 유지한다.
키캡은 전달된 얇은 둥근 테두리 규격으로 그리며 실제 확인 키를 표시한다.
전역 HUD와 같은 뷰포트 레이어의 상단에 표시해 퀘스트 마커가 카드 위로 겹치지 않게 했다.
원본은 레이어 없는 생성 이미지이므로 전용 리소스도 픽셀 동일 복원은 아니다. 성운/별 위치/서체 차이는 Production/2026-10-21/handoff.txt에 명시되어 있다.
현재 T_RustySword 원본은 검은 불투명 배경을 포함한다. UI는 원본 색/알파를 그대로 보존하므로 해당 아이콘은 별도 아트 수정 대상이다. 이 변경에서 기존 아이템 데이터/아이콘은 수정하지 않았다.

표시 데이터
콘텐츠 브라우저의 /Game/Constellation/UI/ItemAcquisition/DA_ItemPresentation_Template 를 아이템별로 복제한다.
Presentation의 Sprite, Name, Description을 입력한다. 템플릿 이름/설명은 의도적으로 비워 두었다.
현재 Sprite는 실제 기존 상자에서 사용하는 coin_icon이다. 승인 시안의 검/열쇠와 예시 문구는 게임 데이터에 추가하지 않았다.
SpriteScale과 SpriteOffset으로 아이템별 크기/위치를 조정한다. 이미지 종횡비를 유지하고 영역 밖으로 잘리지 않도록 제한한다.
AppearanceSound는 승인된 등장 효과음을 선택하는 선택 항목이다. 현재 미연결이며 무음이다.

Blueprint 이벤트
상자 개방 또는 건네받기 핵심 동작 완료 뒤 Show Special Item Definition 노드를 호출한다.
Definition에 해당 데이터 에셋을 지정하고 Quantity를 전달한다(기본 1, 2 이상만 표시).
Confirm Key를 비우면 현재 IA_Interact의 실제 키보드 바인딩을 사용한다. 게임패드 전용 연출은 해당 확인 키를 명시할 수 있다.
Completed 핀으로 다음 연출을 연결한다. Cancelled는 취소/중단 처리에 연결한다.
Request의 Cancel로 해당 요청만 취소하거나 ItemAcquisitionSubsystem.CancelAll로 전체를 취소한다.
여러 요청은 순서대로 표시한다. 표시 중에는 이동/공격 입력을 차단하고 배경 월드 시간은 계속 흐른다.
긴 본문은 마우스 휠, PageUp/PageDown 또는 패드 방향키 위/아래로 읽는다.

SceneDirector
/Game/Constellation/UI/ItemAcquisition/BP_ShowSpecialItem 을 아이템별로 복제하고 기본값 Definition을 설정한다.
Director의 Actions 목록에 해당 Blueprint 클래스를 키로 등록한 후 GameAction 노드에서 그 키를 사용한다.
Action Parameters.Amount는 표시 수량이며 1 이상이어야 한다.
카드를 기다리는 동안 Director 진행을 멈추며 확인하면 재개한다. 취소/스킵은 진행을 종료하고 대기 요청을 정리한다.
기존에 외부에서 걸어 둔 Director 일시정지 상태는 보존한다.

지급 정책
이 UI와 데이터 에셋은 표시 전용이다. 아이템/재화 지급, 회수, 저장을 하지 않는다.
기존 상자의 지급·개방 저장 흐름과 일반 획득 UI를 일괄 교체하지 않았다.
실제 아이템 이름/설명 데이터가 없으므로 템플릿을 채운 뒤 기획자가 지정한 특별 이벤트에 연결해야 한다.
이름/설명/이미지가 없는 데이터 또는 유효하지 않은 수량은 표시 요청을 취소한다.

구현
Source/Constellation/ItemAcquisition*: 위젯, 데이터, 큐, 입력 보호, Blueprint async 및 SceneDirector 어댑터.
tools/setup-item-acquisition.py: 없는 템플릿/호출 에셋만 생성하며 기존 에셋을 덮어쓰지 않는다.
tools/verify-item-acquisition-pie.py: 격리된 테스트 세이브로 실제 이미지, FIFO, 새 확인 입력, 취소, 입력 복원, 재화 불변 검증.
검증용 화면의 설명은 QA 문구이며 실제 아이템 설정에 저장하지 않는다.
