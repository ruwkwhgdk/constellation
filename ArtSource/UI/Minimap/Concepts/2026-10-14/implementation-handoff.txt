최신 시각 기준

이 이미지가 이전 단순 원형 테두리 시안보다 우선입니다. 작은 금빛 별자리·점선·별가루를 원형 테두리 바깥에 넣습니다. 지도와 범례의 층 이동 표식은 화살표 없는 계단만 사용합니다.
이미지의 학교 평면도와 배경은 생성된 예시이지 실제 맵 데이터가 아닙니다. 실제 레벨로부터 제작해야 합니다. 시트 제목, A/B/C 비교 패널, 범례를 게임 화면에 그대로 붙이지 마세요. 시안의 작은 배치 예시에 남은 HP/ST 글자는 최신 HUD에서 제거된 상태이므로 다시 추가하지 마세요.

확정된 동작
1. 폐교: 플레이어가 이동한 주변을 점진적으로 공개하되 벽 너머 방과 다른 층은 공개하지 않습니다. 방 진입만으로 방 전체를 공개하는 방식은 이번 기본값이 아닙니다.
2. 기록: 사망 및 지역 재입장 후에도 현재 탐색 기록 유지. 기존 저장 흐름으로 저장한 뒤 게임을 다시 켜도 복원. 사망 시 과거 탐색 상태로 되돌아가지 않도록 다른 저장 복원 경로와 조율합니다. 디스크 기록은 기존 저장 정책과 합리적으로 연결하고 매 프레임 저장하지 마세요.
3. 현재 목표: 미탐색 지역에서도 위치/방향을 표시하지만 주변 지형은 가려 둡니다. 예전 이미지 A에 목표가 없는 것은 초기 예시이며 이 최종 규칙이 우선합니다.
4. 좌측 상단, 북쪽 고정, 플레이어 중심. 플레이어 위치에 따라 지도만 이동, 방향 화살표와 작은 카메라 부채꼴 회전.
5. HP/스태미너는 현재 하단 중앙 유지. 입력/커서/일시정지에 영향 없는 HUD.
6. 지형 공개와 표식 공개 정책 분리. 미탐색 목표 표시가 문/계단/보물/적 전체 공개를 의미하지 않습니다. 일반 문·계단은 발견된 지도 영역에서 표시, 현재 목표만 위 규칙으로 별도 취급.
7. 범위 밖 현재 목표는 원형 가장자리의 방향 표식으로 표현. 여러 목표를 전부 노출하기보다 활성 목표를 우선하며 기존 퀘스트의 실제 목표 데이터 경로를 확인하세요. 실제 위치 데이터가 없다면 임의 목표를 만들지 말고 기획자가 지정할 수 있는 명시적 목표 연결 지점을 제공하고 한계를 보고하세요.
8. 층별 지도 분리. 계단 아이콘에는 방향 화살표를 붙이지 않지만 내부 데이터에는 연결되는 두 층을 유지합니다. 다른 층의 목표는 현층 목적지처럼 오해하지 않도록 처리하고 현재 층 정보와 조합해 명확히 검증하세요.

지도 데이터와 공개 방식
- 지역별로 이동 탐색형 / 오브젝트 해금형 선택 가능.
- 지도 원본·지역/층 좌표 정보·탐색 마스크·전체 해금 상태·표식 정보를 분리.
- '주변 범위 공개'와 'Region ID 전체 공개'를 공통 시스템에 제공. 오브젝트 상호작용에서 호출할 수 있는 명확한 Blueprint/API 진입점 마련.
- 부분 탐색 후 전체 해금, 중복 전체 해금이 안전하게 동작하고 저장/로드로 유지.
- 실제 오픈월드 맵이나 해금 오브젝트를 새로 제작하는 것은 범위 밖. 호출 예시/검증으로 기반을 확인.
- 원본 지도 생성은 실제 폐교의 벽·바닥·통행 가능한 공간과 층을 반영한 읽기 쉬운 평면도. 지붕/소품이 통로를 덮는 원시 탑뷰 캡처에 의존하지 마세요.
- 벽 차단과 층 구분을 고려한 공개 구현. NavMesh가 통로 추출에 유용할 수 있지만 문/계단 의미와 플레이어 통행 가능성을 자동으로 보장하지 않는다는 점을 확인.
- 층 전환 경계의 흔들림을 방지하고, 사다리/함정문/특수 이동 등 현재 실제 연결 구조를 먼저 확인하여 표현.

출입구·계단 제작 흐름
- 실제 문 Blueprint/계단 또는 연결 액터의 타입·태그·메타데이터로 자동 수집·표식 배치.
- 정보가 없는 형상은 자동 추정 결과를 확정하지 말고 후보 또는 명시적 마커로 보완.
- 기획자에게 표시/숨김, 위치 보정, 표식 종류, 소속 층/연결 층을 편집할 수 있게 제공.
- 장식용 문/막힌 출입구 등 예외를 제외할 수 있어야 함.
- 원본 재생성 시 안정적 식별자에 기반하여 수동 보정을 보존하고 중복 표식을 만들지 않음.
- 모든 문과 계단을 기획자가 미니맵 위에 수작업 배치하는 방식보다 자동 수집+예외 보정을 우선.

아트
- 원형 지도, 얇은 금빛 이중 테두리, 바깥쪽 일부 원호의 금빛 별자리 장식.
- 지도 내부: 남색 미탐색 영역, 회청색 바닥, 밝은 회색 벽/출입구 윤곽.
- 아이보리 방향 화살표=플레이어, 금빛 별=목표, 문 모양=출입구, 단순 계단=층 이동.
- 장식은 지도 정보를 가리지 않게. 북쪽 N 가독성 유지. 장식은 표식과 혼동되지 않게 지도 외곽에 고정.
- 1920x1080에서 약 230~260px 지름 및 안전 여백은 조정 가능한 출발값이며 시안 크기를 그대로 게임 크기로 사용하지 않음.
- 현재 지역/층 표시, 한글 가독성, 다른 HUD와 충돌 확인.
- 지도 이동/공개와 무관하게 별 장식이 과하게 계속 반짝이지 않게.
