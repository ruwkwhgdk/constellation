필수 아트 조건:
- 시안의 남색/성운 배경은 제외. 현재 재생 중인 컷신이 그대로 보이는 투명 오버레이로 제작.
- 비교 시트의 제목, 01~04 번호, 설명 캡션, 구분선은 게임 UI에 포함하지 않음.
- 화면 전체 배경 이미지, 암막, 블러, 큰 불투명 패널을 추가하지 않음. 아이콘/선 가독성은 국소적인 얇은 외곽선 또는 작은 그림자로 확보.
- 금빛 별/궤도와 아이보리 입력 표시를 유지. 이미지 전체를 HUD에 붙이지 말고 필요한 요소를 분리하여 제작.
- 기본 위치는 중앙보다 약간 아래. 노드에서 화면 위치 조정 가능. 입력 활성화 동안 위치 고정. 실제 컷신/밝고 어두운 배경/DPI에서 검증.
- 결과 텍스트(성공/실패 등) 대신 별빛 완성/단절과 절제된 효과음으로 전달.

QTE 4종:
1. 단일 클릭: 좌클릭 1회. 마우스 왼쪽 버튼 강조, 얇은 금빛 원형 궤도.
2. 연속 클릭: 설정 횟수 이상의 독립적인 좌클릭. 안쪽 금빛 진행 궤도 충전. 누른 상태나 프레임 반복을 연타로 세지 않음. 기본 진행량 감소 없음. 횟수 숫자 표시 없음.
3. 방향 드래그: 키보드 WASD가 아님. 시작점에서 좌클릭을 유지한 채 지정 방향으로 최소 거리를 이동하면 즉시 성공. 짧은 직선 경로, 시작/도착 별, 방향 화살표, 안내 손가락, 별도 작은 시간 링. 시안은 오른쪽→왼쪽 예시이며 방향 설정 가능. 경로선은 안내용; 정확한 선 추적을 요구하지 않음. 각도 허용 범위와 최소 거리 설정. 조기 버튼 해제 시 기본 재시도.
4. 따라 그리기: 시작 별에서 누르고 설정된 곡선 경로를 순서대로 따라 도착점까지 이동. 진행 구간 금빛, 남은 경로 점선. 적절한 판정 폭/이탈 허용을 설정. 끝점으로 바로 점프하거나 커서 순간이동으로 중간 구간을 생략해서 성공하지 않음. 안내 손가락은 시작 전 시범을 보이고 실제 입력 중 흐려져 커서와 구분. 큰 이탈/버튼 해제 시 기본 현재 시도 초기화 후 재시도.
- 3,4는 동일한 경로형 시각 체계. 3은 직선 방향/거리 판정, 4는 곡선 순서/경로 판정이라는 차이 보존.
- 기본 클릭 대상은 표시된 QTE의 충분한 히트 영역. 정확한 위치가 불필요한 단일/연속 클릭에는 화면 어디든 입력 옵션 제공 가능.
- 장식과 안내 손가락이 입력을 가로채지 않도록 처리.

대기/판정:
- 완료까지 무제한 대기: 시간 링 없음, 오입력은 재시도. 성공할 때까지 노드 대기.
- 시간제한: 읽을 수 있게 등장한 뒤 타이머 시작, 조건 충족 성공 / 만료 실패. 기본 오입력 재시도, 장면별 즉시 실패 옵션.
- 아이보리 링=남은 시간. 연속 클릭의 안쪽 금빛 링=완료량. 런타임 시간 링은 하나의 연속된 남은 시간 호로 표현(시안의 장식 틈을 분할 타이머로 해석하지 않음).
- 동일 프레임 완료/시간 만료 등 경계에서 결과를 한 번만 확정. 성공/실패/취소 중복 호출 방지.
- 등장 이전 클릭 및 이전 QTE에서 유지 중인 버튼이 다음 QTE 성공으로 이어지지 않도록 새 입력 경계 처리.

연출 툴:
현재 SceneDirector 관련 코드/노드/비동기 대기/분기/스킵 시스템을 먼저 확인하고 기존 구조에 맞춰 QTE 노드 추가. 현재 프로젝트에 필요한 실제 구현과 에디터 연결까지 수행.
공통 설정: QTE 타입, 무제한/시간제한, 제한 시간, 화면 위치, 입력 허용 조건, 실수/재시도 처리.
타입별: 목표 클릭 횟수; 드래그 방향/최소 거리/각도 허용; 경로 데이터/판정 폭.
출력: 성공 / 실패. 컷신 중단/건너뛰기는 일반 실패와 구분되는 취소 정리 경로로 처리.
한 번에 활성 QTE 하나만 표시. 기존 게임 입력과 충돌하지 않게 하고 종료 시 입력 모드/커서/포커스 상태를 복원.
컷신의 QTE 대기와 엔진 전체 정지를 구분. 무제한 대기는 연출의 지정 유지 구간에서 기다리되 UI/입력은 동작해야 함. 컷신 계속 재생하며 시간 안 입력받는 방식도 지원할 수 있게 연출 정책 분리. 무제한 대기의 유지 애니메이션/루프는 장면 제작자가 지정하며 임의 동작을 만들지 말 것.
성공 입력 판정은 즉시 확정. 짧은 UI 퇴장 연출 때문에 후속 컷신 반응을 불필요하게 지연하지 않음.
컷신 일시정지 시 QTE 타이머/진행 일시정지 정책 일관 적용. 스킵, 장면 교체, 종료, 포커스 상실, 반복 실행의 정리 처리 확인. 기존 SceneDirector 스킵 정책과 정합성 유지.

등장 약 0.2초, 성공 빛 응축/파동 약 0.25초, 실패 주황빛/궤도 단절 약 0.3초.
전체 화면 번쩍임 금지. 부드러운 로컬 효과. 효과음은 사용 가능한 승인 리소스를 사용하고 없으면 연결 지점 마련 후 미연결 사실 보고.
