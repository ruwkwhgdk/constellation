구성
- 화면 중앙보다 약간 위, 가로 중앙 정렬.
- 상단 작은 금빛 별 5개와 얇은 연결선. 중앙 별만 조금 더 밝게.
- 주제목: 폐교. 따뜻한 아이보리, 가독성 좋은 한글 명조 계열 후보.
- 얇은 금빛 구분선과 작은 마름모.
- 부제목: 텅 빈 교실. 주제목보다 작게, 이번 수정처럼 여유 있게 아래 배치.
- 뒤쪽 국소 영역에 투명한 청색 성운/음영과 드문 별가루. 불투명 패널과 전체 화면 암전 없이 실제 풍경이 보이도록.
- 원본 대비 간격만 조정한 v2를 우선한다. 생성형 목업이므로 픽셀 좌표는 명세가 아니다.
- 초기 배치 참고: 이미지상 주제목 하단~부제목 상단은 주제목 글자 높이와 비슷한 여백. 구분선을 그 사이에 균형 있게 배치. 실제 폰트 메트릭과 DPI에서 미세 조정하고 간격을 편집 가능한 값으로 제공.

제작 및 연결
- 목업 전체를 화면에 붙이지 말 것. 교실 배경은 생성된 예시이고 UI 리소스가 아니다.
- 주제목/부제목은 실제 동적 FText 위젯. 별, 연결선, 구분선, 성운은 분리된 리소스/레이어로 구성하여 애니메이션 가능하게.
- 프로젝트의 현재 AGENTS.md와 기존 UI 제작 방식을 확인하고 진행.
- 기존 WBP_RegionTitle, BP_RegionTrigger, DT_RegionStringData 경로를 먼저 확인하여 표시 호출과 문자열 데이터를 재사용. 폐교 문구를 모든 지역에 하드코딩하지 말 것.
- 이전 조사에서는 SchoolOpeningSceneActor.cpp 정상 종료 경로가 RegionTitleName/RegionTitleDesc를 설정하고 HitTestInvisible로 표시, 4초 타이머로 제거했다. 현재 코드 재확인 후 위젯 애니메이션과 외부 제거 타이머 충돌을 피할 것.
- 같은 작업공간에 다른 작업의 변경이 있으므로 관련 변경만 수행.

연출 초깃값 제안 (사용자 확정 수치가 아닌 구현 후 조정할 값)
0.0~0.4초: 첫 별 점등.
0.4~0.9초: 별자리 연결 및 제목/부제 등장.
0.9~3.2초: 읽기 위한 유지.
3.2~4.0초: 텍스트/선/성운 페이드 아웃, 마지막 별 소멸.
입력 모드, 커서, 이동/시점, 일시정지를 변경하거나 포커스를 빼앗지 않는다.
재방문 축약, 반복 진입 제한, Toast와 표시 우선순위, 사운드는 앞선 기획의 제안일 뿐 이번 요청에서 확정된 기능은 아니다. 우선 기존 트리거 정책을 유지하고 아트/표시 연출에 집중.
