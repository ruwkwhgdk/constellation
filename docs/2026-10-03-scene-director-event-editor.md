# Scene Director 편집 UI 확장

사용자 요청: 입력 방식에 현재 값 추가. 상단 노드 생성 버튼은 제거하고 중앙 그래프 우클릭 → 대분류 → 종류 방식으로 변경. 좌측에 우측과 같은 고정 메뉴 공간을 마련하고 동일 연출 에셋에 여러 이벤트 그래프를 생성/선택.

- 현재 값: 노드 시작 시 현재 위치/회전 + Offset. Key 불필요. 기존 절대/Key 값 및 현재값 가산 옵션 유지.
- 좌측: 이벤트 목록, 추가 버튼, 현재 이벤트 이름 편집. 각 이벤트의 노드·NPC·카메라·Vector3·생성 시퀀스 독립 보관. 기존 그래프는 첫 이벤트로 보존.
- 중앙: 캐릭터(NPC 추가/애니메이션/이동), 카메라(샷/이동·회전), 흐름 제어(대기/합류) 우클릭 하위 메뉴. 시작/종료는 이벤트 생성 시 자동 배치. 우클릭 좌표에 생성. 핀 드래그 메뉴에서는 새 노드 자동 연결.
- 전환: 현재 편집 내용 보존, 미리보기 정리, 대상 그래프와 우측 목록 교체. Undo 이후에도 현재 이벤트와 편집 데이터 일치.
- 저장: 루트 에셋 안에 이벤트 하위 객체 저장. 전체 이벤트 시퀀스 재생성 및 저장. 실행기는 공개 루트 에셋과 선택한 이벤트 이름을 저장하여 레벨의 비공개 하위 객체 참조를 방지. 런타임 FindEvent(Key)로 원하는 이벤트 조회 가능.
- 검증: 메뉴 분류/생성 좌표/자동 연결/Undo, 이벤트 추가·전환·독립성·이름 중복·Undo 및 영구 저장, 기존 17개 테스트, 실제 화면 렌더링과 빌드.
