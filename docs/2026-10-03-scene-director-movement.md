# Scene Director 카메라·Vector3 저장 및 이동 확장

사용자 확정: Key 참조는 저장 Vector3 + offset. 선택 옵션으로 노드 시작 시 현재 위치/회전도 더한다. 에디터 종료 확인.

1. 데이터: 기존 enum 뒤에 CharacterMove/CameraMove 추가. 위치/회전 입력 구조(절대/Key, offset, 현재값 가산), 속도/시간 선택, NPC별 걷기·달리기 클립과 전환 속도. 에셋에 카메라/Vector3 배열 및 안정 ID 저장. 구버전 카메라는 기존 위치·화각을 유지하여 자동 등록.
2. 이동 일정: 시작 시점 이전의 동일 대상 이동 결과로 출발점 계산. 동시에 같은 대상을 이동시키거나 순서 없는 병렬 경로에서 같은 대상을 바꾸는 경우 오류. 속도 모드는 거리/속도로 시간 계산. 시간 모드는 거리/시간으로 애니메이션 선택. 30fps 선형 이동, 회전은 Euler 각 축의 최단각 보간.
3. 시퀀스: NPC·카메라별 하나의 transform track에 이동 키 생성, 이동 후 도착 위치 유지. 카메라 Key 재사용 시 동일 binding 유지. 없는 Key는 기본 카메라 등록. 활성화 옵션으로 카메라 이동 중 촬영 여부 선택(기본 켜짐). 교차 페이드 자체는 이번 요청의 저장 기반 위에 후속 확장.
4. UI: 우측 NPC/카메라/Vector3 영역 구분선. 카메라 초기 위치·회전·화각 및 Vector3 Key·값 편집. 노드에서 Key 선택/입력. 이름 변경 시 참조 갱신. 이동 노드와 기존 완료 대기·병렬·합류 규칙 통합.
5. 검증: 먼저 새 이동 스케줄 테스트 실패 확인. 절대/Key/현재값 가산, 속도/시간, 연속 이동, 키 누락/충돌, 카메라 재사용, 실제 이동 좌표·회전과 애니메이션 평가, 저장/Undo, 기존 13개 테스트, 렌더링, Shipping 빌드.

걷기/달리기는 NPC 추가 노드에서 해당 캐릭터의 클립을 한 번 등록한다. 이동 노드 자동 모드에서 실제 이동 속도와 NPC별 달리기 전환 속도를 비교하여 선택한다. 직접 지정 모드에서는 선택한 클립을 이동 동안 반복한다. 기존 ABP의 임의 변수명은 추측해 수정하지 않는다. 직선 연출 이동이며 NavMesh 경로 탐색은 범위 밖이다.
