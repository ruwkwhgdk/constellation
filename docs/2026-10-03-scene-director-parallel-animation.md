# Scene Director 병렬과 애니메이션 구현 계획

사용자 요청: Delete 키 삭제, 툴 내부에서 보이는 장면 미리보기, 노드별 완료 대기, 다중 분기/합류, NPC String Key 목록, 애니메이션 노드.

- [x] 데이터 v2: 기존 Next를 NextNodes 배열로 읽기 시 변환. 기존 에셋은 덮어쓰지 않고 저장 시 새 구조 반영.
- [x] DAG 스케줄: 완료 후 다음 실행 기본 true. false이면 단일 후속 노드를 즉시 실행. 다중 입력과 종료는 앞 경로의 모든 진행 중 동작까지 완료 후 한 번 실행. 순환/누락/중복/충돌 거부.
- [x] NPC 목록: 생성 노드의 Key와 BP를 원본으로 자동 목록화. 목록에서 대상 키 지정. 런타임 키 조회 API 제공. 키 변경 시 대상 참조 함께 갱신.
- [x] 애니메이션: 대상 키, AnimSequence, 시간. 클립 한 번을 입력 시간에 맞춰 재생. 호환 스켈레톤과 중복 트랙 검사. 원본 리소스 변경 없음.
- [x] 미리보기: 도구 내부에 현재 레벨을 그리는 독립 뷰포트. 시퀀서 카메라 컷/스크럽 연동, 밝게 보기, 첫 프레임 즉시 평가. 레벨 뷰포트가 뒤에 가려져도 결과 확인 가능.
- [x] Delete: 그래프 포커스에서만 표준 Delete 명령. 시작/종료 보호, Undo/Redo.
- [x] 검증: 병렬/합류/대기 테스트 실패 확인 후 구현. 생성 트랙/실제 애니메이션 평가/키 조회/미리보기 렌더링/기존 에셋 변환/전체 테스트/Shipping 빌드 확인.

## 완료 및 검증

- UE 5.8.0 Editor Development 빌드 성공.
- Constellation Win64 Shipping 빌드 성공. 전체 Cook/Stage/패키지 실행은 이 검증에 포함하지 않음.
- 자동화 테스트 13개 통과: 기존 선형 그래프·재생 수명 검증, 병렬/합류, 비대기, 다중 연결 저장, 구버전 변환, 애니메이션 트랙/원본 배속 보정, 실제 본 포즈 변화, 활성 NPC 키 조회, 실제 Delete 키와 Undo, 툴 미리보기 카메라 추적 포함.
- RenderOffscreen EditorSmoke 성공. 실제 스켈레탈 캐릭터가 툴 내부 씬에 표시되는 PNG 확인: `Saved/SceneDirector-editor.png`.
- 원본 캐릭터와 애니메이션 자산은 변경하지 않고 테스트용 임시 BP에서 참조함.
- 리뷰에서 발견한 재생 도중 Director 변경 시 NPC 조회 실패를 활성 바인딩 스냅샷으로 수정하고 테스트함.
- Delete 명령 목록은 툴킷이 소유하여 Slate의 약한 참조 때문에 소멸되지 않도록 함.
- 데이터 v1의 버전 기본값이 저장에서 생략된 경우도 legacy Next 존재 여부로 변환함.

사용 안내: `Plugins/ConstellationSceneDirector/README.ko.md`. 기존 에셋은 처음 열 때 생성 및 미리보기 후 저장. 미리보기는 Unlit이며 최종 조명/후처리는 PIE에서 확인.
