# 애니메이션 작업 AI 전달 목록

## 공통 제작 조건
사용자 요청: 이 목록을 별도 애니메이션 작업 AI에 전달하여 제작한다. 전투 시스템 작업에서는 새 애니메이션을 제작하지 않는다.

작업 전 ArtSource/Heroine_Tripo_Review/AnimationWorkflow/SKILL.md를 읽는다. 유지 중인 원본, 160cm 캐릭터, 스타일·얼굴·비율, 94본 게임 스켈레톤을 보존한다. 기존 캐릭터와 다른 스켈레톤을 새로 만들지 않는다. 관련 원본은 해당 워크플로에서 확인한다.

게임 기본 이동 속도는 사용자 요청에 따라 **500cm/s**로 고정했다. 기존 RunSoft는 168cm/s용이라 현재 약 2.98배 재생 중이며, 이는 임시 대응이다. 모션에 맞춰 게임 속도를 낮추지 않는다. 현 시스템은 시험장 단일 노드 재생으로, 최종 AnimBP 전환 품질을 승인한 상태가 아니다.

각 작업의 납품물: 편집 원본, FBX, Unreal AnimSequence/필요한 Montage, 실제 속도 반복 미리보기, 길이·이동량·재생 배속·타격/무적/입력 구간·연결 자세·검수 결과 README. 접지, 공중 프레임, 치마·손·무기 관통, 루프 경계, 시작/종료 자세를 검사한다. 타이밍은 아래의 현재 규칙과 제안값을 구분한다. 기획/전투 코드와 다른 변경은 명시적으로 전달한다.

## 몬스터 추적 연결 후 확인 항목
슬라임 감지·추적·복귀를 연결했으며 현재 기존 AS_Slime_Move를220cm/s 이동에 재사용한다. 새 이동 모션을 우선 제작하기보다는 실제220cm/s 직진/우회에서 접지·미끄러짐·회전과 이동→공격→이동 연결을 먼저 검수한다. 기존 모션으로 부족한 경우에만 보정본 또는 전환 클립을 납품한다. 공격 중 전진 돌진은 현재 액션 정의에서 거리/시간을 설정할 수 있다.

## 기존 자산 재사용
- Attack01: Refined/Animations/AM_player_heroine_new_Attack01_Horizontal. 1초, 현재타격0.35~0.50초, 입력0.50~0.65초.
- RunSoft: Refined/Animations/AS_player_heroine_new_Run_Soft. 기존 제작168cm/s. 500cm/s용 재작업의 참고 원본.
- 대기 및 슬라임 기존 공격: tools/setup-combat-lab.py의 실제 연결 경로를 확인하고 원본을 덮어쓰지 않는다.

AI 전달 시 P0부터 한 작업씩 진행하고, 수치 검사와 실제 속도 시각 검토 결과를 함께 받는다. 이 문서는 제작 요청 목록이며 애니메이션 제작 완료 목록이 아니다.

## 2026-10-05 제작 툴 연결 사항
- 현재 Q/E 샘플은 기존 Attack01을 복제해 기능을 검증했다. 전용 모션 제작 완료로 간주하지 않는다.
- 돌진 이동은 코드의 충돌 대응 RootMotionSource가 담당한다. 납품 클립은 우선 제자리로 만들고, 애니메이션 루트 이동과 중복되지 않게 한다.
- E 범위 타격은 벽을 관통하지 않으며 다른 몬스터 몸체가 뒤의 적을 가리지 않는다. 판정 범위는 효과 크기와 별도로 검수한다.
- 타격 구간은 몽타주 원본 시간(초)으로 지정한다. 배속은 실시간 길이를 바꾸므로 이동 종료·타격·회수 길이를 함께 검수한다.
- 새 몽타주는 제작실의 액션 항목에서 선택하고 새 버전으로 생성한다. 원본 모션의 CombatHitWindow를 직접 수정하지 않는다.
