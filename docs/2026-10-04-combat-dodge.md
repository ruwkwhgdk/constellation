# 회피 이동과 무적 구간

## 조작 및 기본 시험값
전투 시험장에서 Space를 누르면 회피한다. 방향 입력이 있으면 입력 순간의 카메라 기준 WASD 방향, 없으면 캐릭터 정면이다. 회피 중 방향을 다시 바꾸지 않는다.

| Combat 컴포넌트 설정 | 기본값 |
|---|---|
| Dodge Duration | 0.6초 |
| Dodge Distance | 240cm |
| Dodge Stamina Cost | 20 |
| Dodge Invulnerable Start / End | 0.10초 이상~0.30초 미만 |

값은 밸런스 확정값이 아닌 초기 시험용이다. 한 번 시작한 회피는 시작 당시 시간·무적 구간·이동량을 사용한다. 이동·카메라의 기존 프로젝트 기본값은 유지한다.

## 규칙
- 지상에서만 시작한다. 공격·피격 경직·다른 회피 중에는 거절하며 SP가 부족하면 비용 없이 거절한다. 공격 취소 창을 이용한 회피 연계와 회피 선입력은 아직 없다.
- 엔진 CharacterMovement의 Root Motion Source로 수평 이동한다. 캡슐 충돌과 기본 바닥/낙하 처리를 사용한다. 무적은 피해만 무시하며 벽 충돌을 끄지 않는다.
- 회피 동안 일반 이동 입력을 받지 않는다. 마우스 시점은 유지한다. 시작 시 선택한 회피 방향으로 캐릭터가 향한다.
- 무적 구간에서 피해와 피격 경직을 무시한다. 시작/회수 구간의 피해는 회피를 취소하고 기존 피격 경직으로 전환한다.
- RMB 취소, 사망, 소유 해제, 월드 종료 시 회피 이동과 무적을 제거한다. 이미 지불한 SP는 환불하지 않는다.
- 자연 종료 후 공격·일반 이동을 다시 허용한다. SP는 회피 종료 후 기존 1초 대기를 거쳐 초당20 회복한다.
- 앞 공격 종료 뒤 후속타 전환을 기다리는 순간 회피를 시작하면 이전 선입력을 지운다.

## 애니메이션 AI 전달
새 애니메이션은 제작하지 않았다. 현재는 대기 포즈로 이동하는 기능 검증용 회피다. 실제 구르기/스텝 모션 완성으로 취급하지 않는다.

모션 제작 시 **제자리 클립**을 우선 요청한다. 게임 코드가 이동량을 담당하므로 애니메이션 이동을 중복 적용하지 않는다. 0.6초 동작, 240cm 이동, 0.10~0.30초 무적에 맞춰 접지·중심·회수 자세를 제안한다. 구르기/스텝 외형과 최종 이동 곡선은 별도 시각 검토에서 결정한다. 상세 작업 목록은 2026-10-04-combat-animation-backlog.md 참조.

## 검증
- 전체 Development Editor 빌드 성공, 전투 자동 테스트 24/24 통과.
- 무적 전후, SP 부족, 공격·공중 상태 거절, 피격·취소·사망 정리, 실행 중 설정 변경 및 시작 콜백 재진입을 검사했다.
- 실제 게임 -CombatDodgeReview 통과. 카메라 Yaw90도에서 W+Space 입력, 평지 Y방향 이동240.49cm, 벽 앞 이동75.90cm 후 정지, SP20 소비, 무적 중 피해 무시, 회피 종료 후 공격1회 성공.
- 코드 검토에서 시작 알림 중 재진입으로 SP 차감 순서를 우회하는 문제를 발견해 거래 중 시작 차단·비용 스냅샷으로 수정했다. 재검토에서 추가 주요 결함 없음.
- 평지·벽 충돌은 검증했다. 경사·계단·낙하 경계, 손 조작 체감, 전용 회피 모션의 품질은 별도 검토가 필요하다.

## 2026-10-05: 공격에서 회피로 전환하는 구간

F1 → 플레이어 → 공격 항목에서 **공격 중 회피 전환 허용**을 켜고 **회피 전환 시작/종료 (몽타주 s)**를 조정한다. 기본은 꺼짐이므로 기존 공격 중 회피 금지 동작을 유지한다. 각 공격별 설정이며 몽타주나 새 애니메이션을 제작하지 않는다.

- 허용 시 0 ≤ 시작 < 종료 ≤ 몽타주 길이. 시작은 포함하고 종료는 포함하지 않는다.
- 현재 실행 중인 실제 몽타주가 그 구간에 있을 때 Space로 공격을 취소하고 회피한다. 후속 공격 선입력 구간과 독립적인 규칙이다.
- 허용 구간 밖·SP 부족·공중·잘못된 회피 설정이면 공격을 취소하지 않는다.
- 전환에 성공하면 공격 타격 판정과 예약된 후속 공격을 제거한다. 이미 지불한 공격 SP는 환불하지 않고 회피 SP를 추가로 한 번 지불한다.
- 공격 취소 콜백 중 다른 공격/회피의 재진입을 차단한다. 취소 도중 사망·경직·자원 부족 등으로 조건이 달라지면 회피를 시작하지 않는다.
- HUD에는 회피 전환 구간 열림/닫힘을 표시한다. 구간이 열려도 SP·지상 조건이 별도로 필요하다.
- 회피 선입력 예약은 추가하지 않았다. 허용 구간에서 직접 Space를 누르는 방식이다.

공격→회피 전환 검증: 전체 Editor 빌드 및 전투 자동 검사40개 통과. DodgeCancelWindow와 DodgeCancelReentry로 구간 시작/종료, SP/공중 거부 시 공격 보존, 타격·예약 정리, 비용 단일 차감, 취소 콜백 재진입 및 사망 중단을 확인했다. WorkbenchInputWindow에 회피 설정 검증과 schema2 보완 검사를 추가했다. 실제 게임은 1280×720·1600×900의 Save/Load 각 프로세스에서 Space 입력 처리 후 DodgeCancelReview: PASS. SP80→공격10+회피20 차감→50을 확인했다. 검사는 타격 간섭을 차단하고 몽타주를 구간 안으로 이동시킨 뒤 실제 키 입력을 보내므로 사람의 회피 타이밍·모션 품질 평가를 대체하지 않는다. 원본 자산·애니메이션은 변경하지 않았다.
