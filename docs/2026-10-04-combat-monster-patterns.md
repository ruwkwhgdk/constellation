# 몬스터 공격 패턴 데이터 선택

## 이번 범위
고정 공격 하나를 반복하던 시험장 슬라임에 데이터 기반 공격 선택을 연결했다. 목표 감지·내비게이션 추적·복귀·다수 플레이어 선택은 다음 단계다. 현재 목표는 플레이어0이며, 몬스터는 제자리에서 관찰·방향 전환·공격 선택을 수행한다.

## 기획자가 사용하는 에셋
/Game/Constellation/Review/CombatCore/DA_SlimePatterns를 열어 Patterns 배열을 편집한다. 시험장 슬라임의 Pattern Profile 속성에 연결되어 있다. 프로필이 없으면 이전 고정 Action 동작을 유지한다.

| 항목 | 의미 |
|---|---|
| Id | 비어 있지 않은 고유 패턴 이름. 로그와 반복 제한에 사용 |
| Action | 기존 CombatActionDefinition. 피해·비용·쿨다운·몽타주·배속의 원본 |
| Min / Max Distance | 대상 중심 사이 수평 거리(cm), 양끝 포함 |
| Max Angle | 몬스터 정면과 대상 방향의 최대 수평 각도 |
| Require Sight | 시야가 가려지면 제외. 기본 true |
| Weight | 적격 후보 사이의 상대 가중치. 0이면 사용 중지 |
| Max Consecutive | 같은 패턴의 연속 사용 제한. 0이면 무제한 |

순서: 데이터 검증 → 거리·각도·시야·반복 제한 → 실행 가능 여부(자원·쿨다운·행동 상태·모션 호환) → 적격 후보만 가중 선택 → 실행 → 실제 종료 대기 → 다음 판단.

판단 사이 기존 0.6초 대기 구간을 유지한다. 공격은 고정 타이머가 아니라 실제 종료/취소 콜백을 기다린다. 대상이 사망했거나 아군이면 선택하지 않는다. 조건을 만족하지 않으면 다른 제한을 무시해 강제 공격하지 않는다.

적에게 시야가 있고 방향만 맞지 않을 때는 먼저 방향을 바꾸고 다음 판단에 각도를 다시 검사한다. 시야가 가려지면 벽 너머를 향해 새 공격을 시작하지 않는다. 공격 중 타격의 벽 충돌 검사는 기존 공통 처리다.

## 기본 시험 패턴
| Id | 피해 | 배속 | 쿨다운 | 거리 | 가중치 | 연속 제한 |
|---|---:|---:|---:|---|---:|---:|
| Light | 15 | 1 | 1.2초 | 0~180cm | 3 | 2 |
| Heavy | 25 | 0.65 | 2.5초 | 0~150cm | 1 | 1 |

두 패턴 모두 기존 슬라임 공격 모션을 사용한다. Heavy는 속도·피해·선택 규칙 확인용이며 전용 지연 강타 모션이나 전진 돌진 구현이 아니다. 새 모션은 별도 애니메이션 AI 전달 목록을 따른다.

setup-combat-lab.py는 기존 프로필과 행동 데이터를 덮어쓰지 않는다. 몬스터의 Pattern Profile이 비어 있을 때 기본 프로필을 연결한다. 이후 설정한 다른 프로필은 보존한다.

## 선택 이유 확인
적 머리 위 디버그 표시에 Light: Distance, Heavy: Cooldown, Selected Light처럼 제외/선택 이유가 나온다. Combat 컴포넌트의 Last Pattern Decision, Last Selected Pattern에서도 읽을 수 있다.

반복 제한은 시작된 공격을 센다. 피격 등으로 중단되거나 비용 지불 직후 취소돼도 사용 횟수를 되돌리지 않는다. 후보가 한 개뿐인데 연속 제한을 소진하면 적격 후보가 없어 대기한다. 해당 패턴을 계속 쓰려면 제한0을 사용하거나 다른 유효 패턴을 제공한다.

현재 구현은 액션 종료마다 판단하는 시험용 공통 노드이다. 보스별 강인도·공격 허가 토큰·전투 거리 유지·추적/복귀는 아직 없다.
