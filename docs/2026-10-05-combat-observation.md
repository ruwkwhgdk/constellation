# 전투 관찰과 수동 시험 안정화 — 2026-10-05

## 사용
Play-Combat.cmd로 실행한다.
- 양측 상태 카드: 공격 준비 / 실제 타격 판정 / 회수와 몽타주 진행 시간을 표시한다.
- 좌측 아래: 현재 기본 공격 가능 여부, SP 부족과 필요량, 남은 쿨다운, 선입력 시간 구간 및 예약 여부, 최근 입력 결과와 피격을 표시한다.
- F1 → 정상 속도 / 0.25배 관찰: 패널을 닫은 뒤 선택한 속도로 교전한다.
- F1 → 판정 범위 켜기 / 끄기: 주황색 캡슐로 요청한 구체 스윕 범위를 표시한다. 벽에 의한 차단과 실제 명중 여부는 기존 충돌 판정이 결정한다. 시각화 토글은 피해 판정을 끄지 않는다.
- F1 → 상세 상태: 양측 최근 피해 최대12건과 AI 판단을 확인한다. 피해량, 남은 HP, 공격자 구분, 게임 내 시각을 기록한다. 무적 회피는 피해0으로 별도 표시한다.
- 관찰 속도·범위 표시는 프리셋 데이터가 아니다. 재시작·시험장 종료 시 원래 상태로 복구된다.
- 기록은 현재 전투 세션의 관찰용이다. 재시작하면 초기화되고 파일로 자동 저장하지 않는다.

## 표시 의미
공격 구간과 선입력 시각은 몽타주 초 단위다. 재생 배속이나 0.25배 관찰에서는 실제 벽시계 시간과 다르다.
'타격 판정 중'은 실제 타격 창이 열렸을 때만 표시한다. 몽타주 시간만 해당 구간이라고 실제 판정이 열렸다고 표시하지 않는다.
'선입력 시간 열림'은 예약을 받는 시간 구간이다. 다음 공격 실행 시 필요한 SP·쿨다운·상태 검사는 별도로 유지된다.
현재 입력 가능 상태와 최근 입력 결과는 구분한다. 예전 SP 부족 메시지가 남아 있어도 현재 '기본 공격 가능'이면 자원이 회복된 상태다.

## 검증 보완
- 회피 거리0, 무적 시작=종료 설정을 적용 전에 거부한다. 실제 회피 로직과 같은 제약이다.
- 공격 관찰은 자원·행동 상태를 변경하지 않는다.
- 피해 기록은 무효 피해를 추가하지 않고, 실제 차감량과 남은 HP를 기록한다. 과잉 피해는 남은HP로 제한한 양을 기록한다.
- 액션 관찰 및 피해 관찰 자동 검사를 추가했다. 전체 CombatCore36개 검사 통과.
- 실제 게임 검사는 F1 열기/닫기, 입력 칸 포커스, 느린 재생, 사망 후 패널·재시작, 서로 다른 프로세스 간 프리셋 저장/불러오기를 확인한다.

## 변경 범위
CombatObservation, CombatAbilitySystem, CombatHitLedger, SCombatWorkbench와 관련 검사/도구를 변경했다.
전체 빌드를 막던 SceneDirectorViewport.h의 SceneDirectorNodeTypes.h include 누락 한 줄도 보완했다. 씬 편집기 동작 코드는 변경하지 않았다.
애니메이션 제작과 공격/캔슬 규칙 변경은 수행하지 않았다.
