# 실제 전투의 공격·피격 이펙트 지정

Play-Combat.cmd의 CombatTool_v3와 조정 샘플 CombatTool_Tuned_v1에 갤러리의 최신 공격·피격 표시를 활성화한다. 기존 액션·피해량·카메라·애니메이션은 유지한다. 생성기는 앞으로 만드는 모든 v2 전투 캐릭터에 기본 VFX를 명시적으로 연결한다.

## 기획자 작업
Combat-Author.cmd → 완료된 전투 버전 복제 → **공격·피격 이펙트**.
플레이어, 몬스터 공통, 특정 몬스터별로 **이 대상의 이펙트 설정**을 누르고 공격/피격을 각각 지정한다. 개별 적은 공통 설정을 상속하며 복원 버튼으로 다시 상속할 수 있다.

- Default: 기존 검 궤적/슬라임 공격/대상에 맞는 피격 효과.
- Disabled: 해당 공격 또는 피격 효과를 생략.
- Builtin: 갤러리 효과 종류, RGBA 색, 기본 크기에 대한 배율을 지정.
- Niagara: 프로젝트의 NiagaraSystem 자산 경로를 지정. 자산 선택 목록은 NS_ 이름 후보를 제공하며 다른 이름은 직접 입력 가능. 엔진 검증에서 실제 자산 형식을 확인한다.

Niagara의 User.Color와 User.Scale을 사용하는 시스템은 지정값을 받을 수 있다. 시스템 자체가 이 파라미터를 사용하지 않으면 내부 색/입자 크기를 따르고, 컴포넌트 변환 크기는 배율을 적용한다. 최대 유지 시간은0.05~10초이며 공격 효과는 그 전에 타격 구간이 끝나거나 공격이 취소되면 정리된다. 피격 효과는 맞은 대상의 설정으로 생성되며 실제 피해가 수락된 경우만 재생된다. 피격 효과를 끄려면 그 대상의 Hit를 Disabled로 설정한다.

검 궤적을 유지하려면 공격 방식을 Default로 둔다. Builtin/Niagara는 기본 공격 효과를 대체한다. 이 단계는 캐릭터 공통 공격/피격 슬롯이며, 액션별 서로 다른 이펙트나 다중 노티파이 타임라인은 별도 확장 대상이다.

설정 후 입력 검사→새 버전 저장→엔진 검증→맵 제작→플레이한다. F1 튜닝 보고서를 새 버전으로 가져와도 기존 레시피의 이펙트 설정을 보존한다. 이펙트는 수치 튜닝용 F1 패널이 아닌 제작실에서 지정한다.

**이펙트 표시**를 끄면 해당 캐릭터의 공격 효과와 그 캐릭터가 맞을 때의 효과를 생략한다. 공격자의 표시가 꺼져 있어도 맞은 대상의 표시가 켜져 있으면 대상 피격 효과는 재생된다.

## 언리얼에서 지정
CombatLabCharacter의 CombatVFX 컴포넌트에서 공격 이펙트 AttackCue와 피격 이펙트 HitCue를 편집한다. 설정은 맵/블루프린트에 저장된다. Niagara는 하드 자산 참조로 저장해 Cook 참조 수집에 포함된다.
다른 전투 캐릭터에 컴포넌트를 부착하려면 CombatAbilitySystem 초기화 후 Initialize를 호출한다. 이 연결은 확정 타격/타격 창/취소·사망 이벤트를 사용하며 피해를 중복 적용하지 않는다. 전투 시스템을 사용하지 않는 별도 블루프린트에는 자동 연결되지 않는다.

원본 맵 활성화 전 백업은 Saved/CombatAudit/VFXActivation에 저장된다. Play-VFX.cmd의 갤러리 맵과 원본 이펙트 자산은 수정하지 않는다.
