# VFX 작업 커밋 범위 (2026-10-31)

초기 검 공격/피격, 슬라임 공격/피격, 플레이어 피격 반응, 유리 파괴, 달리기 먼지, 동굴 효과와 L_VFXGallery 통합은 기존 c76117be 커밋에 포함되어 있습니다.

이번 커밋은 이후 추가된 ConstellationVFX 전용 변경을 보존합니다.
- 약/강/패링 공격별 검 궤적 프로필 및 폭·수명·밝기 설정 API.
- 확정 접촉 결과 API와 그로기 진입·유지·해제 표현 및 정리.
- 몬스터 노랑/빨강 전조 컴포넌트, 재질, 갤러리 비교 모드와 회귀 테스트.
- DropItem 획득용 Cascade 효과와 재질, 제작·검수 기록.

## 범위와 의존성

VFX 플러그인 내부 구현과 직접 사용하는 신규 에셋만 포함합니다. 기존 갤러리·재질·슬라임 메시/애니메이션은 이미 추적 중입니다. 슬라임 모델·애니메이션 수정은 포함하지 않습니다.

CombatVFXComponent의 후보 선택 연결은 미커밋 CombatActionDefinition의 AttackKind 등 별도 전투 시스템 변경에 의존하므로 이번 커밋에서 제외합니다. MainCombatBridge, MainEnemyGroggy, 본편 BP, 아이템 지급 시스템 및 다른 채팅의 변경도 남겨 둡니다. 제작 기록의 연결 상태는 당시 작업 폴더 기준이며 이 커밋만으로 본편 연결이 모두 제공된다는 뜻이 아닙니다. 공통 VFX API와 갤러리 비교 기능은 해당 어댑터에 의존하지 않습니다.

## 검증 근거

커밋 준비 시 VFX 런타임 모듈의 모든 소스가 기존 검증 프로젝트 Saved/CombatExpansion/vfx1의 소스와 해시 일치함을 확인했습니다. 신규 에셋 3개의 SHA256도 각 납품 문서의 검수본과 일치합니다. git diff --check를 수행합니다.

기존 실행 기록: VFX/CombatVFX 자동화 24개 통과(15개 경고), 후속 전조 검사 기록 및 획득 효과 Preview07 passed=true. 상세 범위와 한계는 개별 납품 문서를 참조합니다. 이번 커밋 준비 과정에서 엔진 빌드·실행·Shipping/Cook를 다시 수행하지 않았으며 현재 공유 작업 폴더 전체의 합격을 주장하지 않습니다.
