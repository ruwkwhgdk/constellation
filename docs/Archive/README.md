## 정리 범위와 보호 항목

총 74개 과거 MD를 원래 상대 경로로 보관했고, 두 ZIP 모두 Drive 다운로드본의 SHA256을 대조한 뒤 원본을 제거했다. 실행 스크립트가 읽는 인수인계 문서, 미완료 식생 문제 기록, 현행 워크플로와 제작 원본은 유지한다.

최초 캐시 정리가 동시 빌드와 충돌하여 중단했다. 다른 UI 작업의 113/113 재생성 빌드 성공을 확인했으며, 이후에는 `Intermediate/`, `Plugins/*/Intermediate/`, 빌드·실행 캐시 및 Unreal 에셋을 추가 변경하지 않았다. 생성 파일의 재생성으로 인해 최초 삭제 용량을 최종 확보 용량으로 해석하면 안 된다.

폐기된 CombatTool_v2 에셋은 최초 정리 중 15개 중 12개만 엔진 API로 삭제됐다. 남은 Guard/DA_Heavy, DA_Light, DA_Patterns 3개는 공유 작업 충돌을 피하기 위해 보존했다. 에셋 정리가 모두 끝났다는 뜻이 아니다.
