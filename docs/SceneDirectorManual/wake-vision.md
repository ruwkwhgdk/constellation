# 눈꺼풀과 시야 회복 연출

연출 편집기의 카메라 메뉴에 `눈꺼풀 연출`, `시야 효과`, `시야 효과 해제`가 추가되었다.

## 눈꺼풀 연출

동작은 Open(열기), Close(닫기), Blink(반복)이다. 시작 개방량은 0=완전히 감음, 1=완전히 뜸이다. 단일 닫기를 만들 때는 시작 개방량을 1로 설정한다. Blink 목록의 항목 수가 깜박임 횟수이며, 각 항목은 개방량 / 뜨는 시간 / 열린 상태 유지 / 감는 시간 / 닫힌 상태 유지로 구성된다. 마지막 개방량·전환·유지를 따로 설정한다. 총 시간은 이 값들의 합으로 계산한다.

S0 최신 설정(2026-10-11 추가 피드백): 검은 화면 1초 → 25% 개방 2초 → 유지 1초 → 닫기 1.5초 → 감은 상태 0.5초 → 55% 개방 2초 → 유지 1초 → 닫기 1.5초 → 감은 상태 1.5초 → 완전 개방 0.5초 → 유지 2초 → 첫 대사. 눈꺼풀 합계 14.5초이며 시작 카메라 준비 약 0.1초가 앞선다. 기존 20.5초 프리셋을 대체한다. 눈꺼풀 경계는 화면 높이의 12% × 닫힘 정도에 해당하는 폭에서 12단계 smoothstep 알파로 흐려진다. 기존 시작 전 추가 대기와 좌우 둘러보기는 생략하고 조사 분기는 유지한다.

## 시야 효과

흐림과 흰 안개는 각각 0~1 값이다. 시작·종료 값과 시간, 안개 색, 선형/부드러운 변화 곡선을 지정한다. 실제 블러는 Slate 배경 블러를 사용하며, 레벨·카메라의 후처리 값을 덮어쓰지 않는다. 눈꺼풀은 곡선과 부드러운 경계를 가진 화면 오버레이이다. 대사/선택지보다 아래에 표시되므로 연출 대사는 흐려지지 않는다. 플랫폼에서 Slate 배경 블러를 비활성화한 저품질 설정은 별도 확인이 필요하다.

S0는 눈꺼풀과 5개의 시야 효과를 함께 진행한다. 0~5.5초는 흐림 .85 / 흰 안개 .22, 5.5~6초(감은 상태)에 .25 / .06으로 전환, 6~10.5초 유지, 10.5~12초(감은 상태)에 0으로 전환, 12~14.5초는 선명하다. 눈꺼풀의 `완료 후 다음 실행`을 끄고 시야 효과를 순차 연결한 뒤 합류 노드에서 동기화하고 첫 대사로 연결한다.

## 해제와 미리보기

`시야 효과 해제`는 눈꺼풀·흐림·흰 안개를 기본값으로 복구한다. 즉시 해제하거나 지정 시간에 걸쳐 서서히 해제할 수 있다. 이미 재생 중인 같은 채널의 효과와 시간 범위를 겹치지 않게 연결한다. 즉시 해제 다음에 같은 시점으로 새 효과를 시작하는 순차 연결은 가능하다.

효과의 최종 값은 다음 효과 또는 연출 종료까지 유지된다. 연출 중단/취소/종료와 월드 종료 시 오버레이를 제거한다. 재생기와 편집기 미리보기는 동일한 시간 평가 함수를 사용해 일시정지, 앞으로/뒤로 시간 이동이 누적 오차 없이 재현된다. 생성된 Level Sequence만 단독으로 재생하는 것은 화면 노드 런타임을 호출하지 않으므로 연출 툴 미리보기 또는 SceneDirectorPlayer로 확인한다.

S0 최초 검은 화면은 눈꺼풀 노드가 실제 시작될 때까지 기존 초기 마스크가 담당한다. 눈뜨기 앞의 카메라 준비/대기 동안 장면이 노출되지 않도록 분리되어 있다.

## 작업 파일

- 기능: SceneDirectorVision, SDirectorVision, SceneDirectorAsset/Compiler/Player 및 SceneDirectorViewport.
- S0 적용: `tools/apply-school-wake-vision.py` (기존 첫 OpenEyes와 대기만 부분 수정, 실행 전 에디터 닫기).
- 적용 전 그래프 백업: `Saved/WakeVision/DA_S0_Opening-before-vision.uasset`.
- 느린 템포 적용: `tools/apply-school-slow-wake.py`; 변경 직전 에셋은 `Saved/WakeVision/SlowRevision-20261011/`에 백업한다.
- 자동 검사: `Constellation.SceneDirector.Vision.*`; 실제 맵 검사: `tools/verify-school-wake-vision.py`.
- 실제 맵 검사는 격리된 `SceneReleaseValidation` UserDir에서 실행한다. 두 조사 순서, 깜박임 2회, 선택지 전 선명도 복구, 도중 취소 시 효과/입력 복구를 확인한다.


최신 통합 적용 스크립트: `tools/apply-school-opening-polish.py`. 14.5초 설정과 꾸밈 6개, 가구를 피하는 꼬마 접근 경로를 적용한다. 이전 slow-wake 적용 스크립트는 과거 20.5초 프리셋이므로 최신 에셋에 재실행하지 않는다. UI 선택지 목록은 Slate CustomPrepass에서 갱신하여 첫 표시 때 크기가 한 프레임 뒤에 바뀌는 것을 방지한다.
