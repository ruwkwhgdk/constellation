# Gaea 하이트맵 워크플로우 — 존 맵을 지형으로 변환하기 (초보자용)

[open-world-level-design-guide.md](open-world-level-design-guide.md) §2/§3-1단계에서 언급한 "Gaea로
매크로 하이트맵을 먼저 만들고 엔진에 임포트" 작업을 처음부터 끝까지 실행하는 상세 가이드입니다.
Gaea를 처음 쓰는 것을 전제로, UI 개념부터 Unreal 임포트까지 다룹니다.

**전제 가정**: 디자인 맵의 색을 고도 힌트로 해석합니다 — 짙은 빨강(외곽 테두리) = 고산/절벽,
주황·노랑 = 완만한 언덕·고원, 초록 = 중심 평지, 파랑 = 호수(저지대). 색이 순수 위험도이고
실제 고도 의도가 다르다면 §3의 그레이스케일 매핑 표만 바꾸면 되고 나머지 구조는 동일합니다.

---

## 1. Gaea UI 3분 요약

Gaea는 Substance Designer처럼 **노드 그래프**로 지형을 절차적으로 쌓는 툴입니다. 실행하면:

- **Build 탭(중앙)**: 노드를 배치하고 선으로 연결하는 그래프 캔버스. 여기가 작업 공간입니다.
- **왼쪽 노드 팔레트**: 카테고리별로 노드가 분류되어 있습니다.
  - `Primitive` / `Generate`: 지형의 기본 형태를 만드는 노드 (Mountain, Ridge, Crater, Voronoi, Perlin 등)
  - `Modify`: 형태를 가공 (Combine, Warp, Terrace, Clamp, Blur, Shear)
  - `Erode` / `Simulate`: 침식·풍화 시뮬레이션 (Erosion2, Thermal2, Rivers, Sea, Snow)
  - `Derive`: 기존 지형에서 마스크 추출 (Slope, Height, Occlusion → 나중에 UE 머티리얼 블렌딩에도 유용)
  - `Output`: 최종 결과를 파일로 내보내는 노드
  - `Utility`: File(외부 이미지 불러오기), Draw(직접 손으로 그리기), Combine 등
- **오른쪽 Properties 패널**: 선택한 노드의 파라미터 슬라이더.
- **뷰포트**: 3D 프리뷰와 2D Map(탑다운) 뷰를 전환할 수 있습니다. **탑다운 Map 뷰가 존 맵과
  비교하며 작업하기에 가장 편합니다** — 참고 이미지를 두 번째 모니터나 옆 창에 띄워두고
  나란히 맞춰보세요.
- **Build/Bake**: 그래프 편집 중에는 저해상도 프리뷰로 빠르게 계산됩니다. 최종 해상도로
  파일을 뽑을 때만 하단의 Build 큐에서 "Build"를 실행합니다(이때가 느립니다 — 특히
  Erosion2가 무겁습니다).

무료 티어(Gaea Indie/Community)는 개인 프로젝트의 매크로 패스에는 충분하지만 최대 출력
해상도에 제한이 있으니, 최종 빌드 전에 현재 라이선스의 해상도 상한을 확인하세요.

## 2. 사전 준비: 존 맵을 그레이스케일 가이드 이미지로 변환

Gaea 안에서 바로 색맵을 인식시킬 수는 없으므로, 이미지 편집기(무료인 **GIMP** 기준으로 설명 —
Photoshop이 있다면 괄호 안 도구 이름으로 그대로 대응됩니다)에서 먼저 **흑백 고도 가이드
이미지**를 만듭니다.

### 목표 회색 값 매핑표

| 원본 색 | 의미(가정) | 채울 회색 값 (0=검정/최저, 255=흰색/최고) |
|---|---|---|
| 짙은 빨강 (외곽 테두리) | 고산/절벽, 플레이 경계 | 220–255 |
| 주황 | 험한 고지 능선 | 170–210 |
| 노랑 | 완만한 언덕·고원 | 120–160 |
| 초록 | 중심 평지 | 70–100 |
| 파랑 (호수) | 저지대 함몰부 | 0–15 |
| 지도 바깥 흰 배경 | 월드 바깥(플레이 불가) | 0 (검정 — 산 테두리보다 낮게 둬서 자연스러운 절벽 폴오프) |

이 지도는 색이 존 사이에서 계단 없이 부드럽게(초록→노랑→주황→빨강) 섞여 있는 **그라디언트
히트맵**입니다 — 즉 이미 "값 → 색"으로 인코딩된 스칼라 필드에 가깝습니다. 그래서 딱 5개 색을
찾아 칠하기보다, 중간 톤(연두빛 노랑, 다홍빛 주황 등)도 눈에 보이는 대로 몇 번 더 선택해서
그 사이 회색 값으로 채우면 훨씬 자연스럽게 이어집니다.

### GIMP 단계별 절차

1. **아이콘/선/텍스트 정리** (권장): 도로선, 몬스터 아이콘(M1~M5), 숫자 배지, 상자·모닥불
   아이콘 등은 지형 정보가 아니므로 지워야 합니다.
   - 레이어가 분리된 원본 파일(psd 등)이 있다면 아이콘 레이어를 끄고 배경 색 레이어만
     남기세요 — 가장 깔끔합니다.
   - 평면화된 이미지(스크린샷 등)만 있다면 `Filters → Blur → Median Blur`(반경 5~10px)를
     배경 전체에 적용하세요. 얇은 선과 작은 아이콘은 대부분 주변 색으로 뭉개져 사라집니다.
     완벽하지 않아도 됩니다 — 남은 잡음은 5단계 블러가 한 번 더 지워줍니다.
2. **색상별 선택 → 채우기** (`Select → By Color`, Threshold 20~30 정도):
   - 파란 호수 영역 클릭 → 선택됨 → `Select → Grow` 3~5px(경계/아이콘 구멍 메꾸기) →
     전경색을 목표 회색(예: RGB 10,10,10)으로 설정 → `Edit → Fill with FG Color`
   - 같은 방식으로 초록 → 노랑 → 주황 → 짙은 빨강 순서로, 표의 회색 값을 채웁니다.
   - 그라디언트 중간 톤(연두-노랑, 주황-빨강 경계)이 눈에 띄면 몇 번 더 클릭해서 그 사이
     값으로 채워주면 더 매끄럽습니다. 완벽히 다 잡을 필요는 없습니다.
3. `Image → Mode → Grayscale`로 전환해 색이 안 남았는지 확인.
4. `Filters → Blur → Gaussian Blur` 반경 10~20px 적용 — 색을 채우며 생긴 계단식 경계를
   부드럽게 풀어줍니다. **이 단계를 건너뛰면 Gaea에서 지형에 부자연스러운 "단(段)"이 생기니
   꼭 하세요.**
5. `Image → Scale Image`로 512×512~1024×1024로 리사이즈(최종 하이트맵 해상도가 아니라 저주파
   "의도" 가이드용이라 이 정도면 충분).
6. `File → Export As → zone_guide.png` — 8bit 그레이스케일 PNG로 저장.
7. 도로(검은 선)는 이 단계에서는 무시하세요 — §6에서 별도로 다룹니다.

### 더 정밀하게 하고 싶다면

원본 이미지 파일을 저장해서 경로를 알려주면, 색상 앵커 포인트(예: 이 지도에서 실제 쓰인
파랑/초록/노랑/주황/빨강의 정확한 RGB 값)를 여러 개 뽑아 목표 회색 값으로 보간하는 작은
Python(Pillow) 스크립트를 만들어 자동 변환할 수도 있습니다 — 수작업보다 빠르고 그라디언트를
더 정확히 반영합니다. 필요하면 요청하세요.

## 3. Gaea 노드 그래프 구성 (단계별)

### 3.0 실전: GIMP에서 만든 이미지를 Gaea로 가져오기

1. GIMP에서 §2 마지막 단계대로 `File → Export As`로 `zone_guide.png` 저장 (아직 안 했다면
   지금 하세요). UE 프로젝트의 `Content` 폴더가 아니라 별도 작업 폴더에 저장하는 걸 권장합니다
   (예: `C:\GaeaProjects\Constellation\zone_guide.png`) — Gaea 프로젝트 파일과 소스 이미지를
   같이 관리하기 편합니다.
2. Gaea를 실행하면 빈 Build 그래프가 열립니다(처음이면 New Project로 새로 만드세요).
3. **가장 쉬운 방법**: 방금 저장한 `zone_guide.png` 파일을 Windows 탐색기에서 Gaea 캔버스로
   **드래그 앤 드롭**하세요 — 자동으로 `File` 노드가 생성되고 경로가 채워집니다.
   (또는 캔버스에서 스페이스바/검색창으로 "File" 노드를 직접 찾아 배치한 뒤, Properties 패널의
   경로 필드에서 파일을 직접 지정해도 됩니다.)
4. `File` 노드를 선택하고 Properties 패널에서 **Color Model(또는 Mode) 설정을 "Height"로
   지정**되어 있는지 확인하세요 — 마스크가 아니라 실제 고도 데이터로 취급되게 하는 설정입니다.
   (버전에 따라 이 옵션이 없을 수도 있는데, 그럴 땐 기본값 그대로 두면 됩니다.)
5. 뷰포트를 2D **Map 뷰**로 전환해서, 방금 GIMP에서 작업한 그레이스케일 실루엣이 그대로
   보이는지 확인하세요. 여기서 원본 존 맵과 형태가 맞는지 마지막으로 눈으로 대조하는 게
   좋습니다.
6. 확인됐으면 `File` 노드 출력을 다음 노드(§3.1 표의 2번, `Blur`)에 연결해서 계속 진행합니다.
7. 작업 중간중간 `File → Save As`로 Gaea 프로젝트(.terrain)를 저장해두세요 — 나중 단계인
   Erosion2가 무거워서 크래시가 날 수 있습니다(§9 참고).

### 3.1 노드 순서

아래 순서대로 노드를 배치하고 왼쪽→오른쪽으로 연결합니다. 노드 이름은 Gaea 버전에 따라
약간 다를 수 있으니, 팔레트 검색창에 키워드로 찾으세요.

| # | 노드 | 역할 | 초보자 팁 |
|---|---|---|---|
| 1 | **File** | §2에서 만든 `zone_guide.png`를 불러와 지형의 "저주파 뼈대"로 사용 | Input 경로에 파일 지정. 이 시점에 Map 뷰가 원본 존 맵 실루엣과 거의 일치해야 함 |
| 2 | **Blur** | File 노드 출력을 살짝 부드럽게 | Radius는 낮게(전체 크기의 1–2%) — 너무 많이 흐리면 존 경계가 사라짐 |
| 3 | **Mountain** 또는 **Ridge** (별도 브랜치) | 자연스러운 고주파 노이즈/디테일 생성 | 이 노드는 존 맵과 무관하게 그냥 랜덤 산악 텍스처를 만드는 용도 |
| 4 | **Combine** (2번+3번 입력) | 가이드 지형 위에 자연스러운 디테일을 살짝 덧입힘 | Mode = Add, Ratio 0.2~0.3 정도로 낮게 — 가이드 실루엣이 주도권을 갖고 노이즈는 "양념"만 |
| 5 | **Warp** | 도메인 워프로 존 경계선을 자연스럽게 왜곡 | 사람이 그린 매끈한 블롭 윤곽선을 깨서 지질학적으로 그럴듯하게 만드는 핵심 단계 |
| 6 | **Erosion2** | 수식 침식 시뮬레이션 — 실제 지형처럼 계곡/능선을 깎음 | §4 참고. 여기서 지형이 "진짜처럼" 보이기 시작함 |
| 7 | **Thermal2** (선택) | 급경사면의 풍화/붕적 처리로 절벽 각도를 완화 | 산맥 테두리가 너무 칼같이 서 있으면 추가 |
| 8 | **Clamp** 또는 **Autolevel** | 최종 높이 범위를 0–1로 정규화 | Output 직전에 배치해 극단값 클리핑 방지 |
| 9 | **Height (Output)** | 최종 익스포트 노드 | §5에서 Build 설정 |

호수(파랑 영역)와 도로는 이 메인 체인과 별도로 §6/§7에서 처리한 뒤 Combine으로 합류시킵니다.

## 4. Erosion2 파라미터 — 처음엔 이 3개만 보세요

Erosion2는 슬라이더가 많아 처음엔 압도되기 쉽습니다. 우선 3개만 조절하고 나머지는 기본값으로 두세요:

- **Duration**: 침식이 진행되는 "시간". 낮으면 원본 형태가 거의 그대로, 높으면 깊은 계곡/침식
  지형. 10~15 정도로 시작해서 프리뷰 보고 올리세요.
- **Downcutting**: 강줄기가 얼마나 깊게 계곡을 파는지. 값이 높을수록 극적인 협곡이 생김.
- **Rock Softness / Erosion Scale**: 값이 낮을수록 바위질(날카로운 능선), 높을수록 부드러운
  침식(둥근 언덕). 존 맵에서 산악 테두리는 낮게, 평지 쪽은 이 값의 영향을 덜 받도록 나중에
  마스크로 분리해도 됩니다(고급 — 처음엔 전체에 동일 값으로 시작).

한 번 돌려보고 Map 뷰에서 존 맵과 비교 → 파라미터 조금씩 조정 → 재빌드, 이 사이클을 저해상도
프리뷰로 여러 번 반복한 뒤에만 최종 해상도로 올리세요(고해상도 Erosion2는 계산이 오래 걸립니다).

## 5. 호수 처리 — Sea 노드 대신 로컬 마스크로

존 맵의 파란 호수는 **바다가 아니라 내륙 함몰지**이므로, Gaea의 전역 `Sea` 노드(전체 지형에서
특정 고도 이하를 모두 물로 채움)를 쓰면 다른 저지대 계곡까지 같이 잠겨버릴 수 있습니다. 대신:

1. §2와 별도로 호수 영역만 흰색인 마스크(`lake_mask.png`)를 하나 더 만듭니다.
2. `File`로 불러온 뒤 `Combine`(Mode = Subtract, 마스크로 사용)을 메인 체인 후반부에 연결해,
   호수 자리만 국소적으로 평평하게 파냅니다.
3. 실제 물 표면(반사, 파도, 수생 식생 경계)은 Gaea에서 만들지 말고, 임포트 후 Unreal의
   **Water 플러그인**으로 처리하세요 — [기존 가이드 §2](open-world-level-design-guide.md)에서
   이미 이 플러그인을 프로젝트 기본값으로 쓰기로 정했습니다. Gaea에서는 "물이 찰 그릇 모양"만
   만들면 충분합니다.

## 6. 도로 처리 — Gaea에서 조각하지 마세요

존 맵의 검은 선(도로)은 Gaea 단계에서 지형에 파넣지 않는 것을 권장합니다. 이유:
POI 위치가 나중에 조금이라도 바뀌면 Gaea 그래프를 다시 손봐야 하기 때문입니다. 대신
[기존 가이드 §3-3단계](open-world-level-design-guide.md)에 정리된 대로, Unreal의 **Landscape
Spline / Water / Brushify(도입했다면)**로 Edit Layer 위에서 조각하세요 — 이러면 POI/경로 변경
시 지형 재스컬핑 없이 스플라인만 옮기면 됩니다. 다만 도로가 험준한 산악 테두리를 가로지르는
구간이 있다면, Gaea 단계에서 그 구간만 넓게 살짝 낮춰(약한 마스크 Combine) 나중에 UE에서
과도하게 깎아내지 않아도 되게 해두면 편합니다 — 선택사항입니다.

## 7. Export 설정 (Gaea → Unreal)

1. 최종 `Height` 노드를 선택하고 하단 Build 큐에 추가합니다.
2. **해상도**: 기존 가이드 §1.2에서 정한 Landscape 해상도 프리셋(1009/2017/4033/8129 등)을
   목표로 하되, Gaea의 빌드 해상도는 보통 2ⁿ+1 계열(1025/2049/4097/8193)이라 정확히 안 맞을
   수 있습니다 — Gaea에서 한 단계 위 해상도로 뽑은 뒤, 이미지 편집기에서 UE 프리셋 크기로
   리사이즈/크롭해서 맞추는 게 가장 속 편합니다.
3. **포맷**: `PNG (16-bit)` 또는 `.r16` (RAW 16-bit) 중 선택 — Unreal Landscape Import가
   둘 다 지원합니다. 처음이면 PNG16이 다루기 쉽습니다.
4. **World/Meters 설정**: Build Definition에서 지형의 실제 최대 높이(미터)를 지정하는 옵션을
   확인하세요 — 이 값이 나중에 Unreal Landscape의 **Z Scale**과 맞아야 산이 납작하게 눌리거나
   과장되게 솟지 않습니다. (예: Gaea에서 최대 고도를 800m로 잡았다면, UE 임포트 시 Landscape
   Z Scale을 그에 맞춰 계산해서 입력)
5. Build 실행 → 완료되면 출력 폴더에서 파일 확인.

---

## 8. Unreal로 임포트

기존 가이드 §1.2에서 이미 Section size(63×63 quads)/Sections per component(2×2)/Edit Layers
활성화를 정해두었으니, Landscape 생성 다이얼로그에서:

1. **Landscape → New Landscape → Import from File** 선택.
2. §7에서 만든 heightmap 파일 지정 → 다이얼로그가 자동으로 해상도를 읽어옵니다. 기존 가이드의
   프리셋과 일치하는지 확인.
3. Section size/Sections per component는 기존 가이드 값 그대로.
4. Z Scale을 §7-4의 미터 값에 맞춰 조정.
5. 생성 후, 처음부터 Edit Layers의 별도 레이어(예: `Base_Gaea`)로 넣고 이후 도로/POI/디테일
   작업은 그 위에 새 레이어를 쌓으세요 — 나중에 Gaea 매크로 패스를 다시 뽑아 교체해도 손
   디테일 레이어가 보존됩니다.

## 9. 초보자가 자주 하는 실수

- **처음부터 최종 해상도로 작업**: Erosion2가 무거워 반복 속도가 죽습니다. 저해상도 프리뷰에서
  실루엣이 존 맵과 맞을 때까지 반복한 뒤에만 최종 빌드하세요.
- **디테일부터 다듬기**: 산맥 테두리 실루엣(경계 역할)이 맞지 않은 채로 언덕 질감을 다듬는 것은
  낭비입니다 — [기존 가이드 §3-1단계](open-world-level-design-guide.md)의 "매크로 먼저" 원칙이
  Gaea 단계에도 그대로 적용됩니다.
- **그래프가 스파게티가 됨**: 노드가 20개를 넘어가면 Frame/Comment 기능으로 "Mountain Rim",
  "Lowlands", "Lake", "Erosion Pass" 같은 구역을 표시해두세요. 나중에 존 위치를 바꿔 재작업할
  때 훨씬 편합니다.
- **저장 습관**: 고해상도 Erosion2 빌드는 사양이 낮은 머신에서 크래시하는 경우가 있습니다.
  Build 실행 전에 저장하는 습관을 들이세요.
