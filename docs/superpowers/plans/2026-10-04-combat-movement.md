# 기본 교전: 이동·시점·잠금 구현 계획
사용자의 계속 진행 및 이동 결함 수정 요청에 따라 기존 기획의 단계 2를 진행한다.
실행: superpowers:executing-plans. 기존 작업 폴더의 전투 플러그인과 시험장만 수정한다.

## 이번 실행 단위
- [x] 카메라 각도별 WASD 재현 테스트를 먼저 추가하고 실패 확인.
- [x] 카메라 기준 이동, 마우스 시점, 회전 권한 충돌 해소.
- [x] 유지 중인 168cm/s RunSoft와 휴식 모션을 연결. 공격 중 이동 모션이 몽타주를 덮어쓰지 않도록 한다.
- [x] Tab 타깃 잠금/해제, 사망·거리·벽으로 잠금 무효화, 시점과 이동 관계 검증.
- [x] 실제 게임에서 키 입력→이동 거리/방향, 공격 후 이동 복귀 확인.
- [x] 기존 10개 코어 테스트와 새 회귀 테스트, 코드 리뷰, 사용법 갱신.

## 범위와 다음 작업
모션 원본을 수정하거나 기존 플레이 BP에 이식하지 않는다. 타깃 잠금 시에도 우선 이동 방향으로 캐릭터를 돌리고 공격 시 타깃을 바라본다. 전용 측면/후진 모션이 없는 상태에서 정면 달리기로 옆걸음을 가장하지 않는다.
3타·회피·피격·스태미나 규칙은 기본 교전의 남은 작업으로 이어간다. 이동 결함이 해결되기 전 이 기능들을 한꺼번에 추가하지 않는다.
