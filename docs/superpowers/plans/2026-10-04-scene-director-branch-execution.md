# 선택지와 조건 분기 실행 구현 계획

**목표:** 선택된 경로만 실행하고 기존 액터와 연출 상태를 유지한다.
**설계:** ../specs/2026-10-04-scene-director-branching-design.md
**실행:** subagent-driven-development 지침으로 편집/경로 처리 작업을 분담하고 주 실행기와 통합·검증한다. 기존 작업 공간에 빌드된 미추적 플러그인과 콘텐츠가 있으므로 현 공간을 유지한다. 커밋하지 않는다.

## 결정과 범위
- 대사 노드의 기존 선택지 배열을 그대로 사용하며 별도 선택지 전용 노드 타입을 중복 추가하지 않는다. 항목별 출력 핀을 제공한다. Condition, SetBool enum은 뒤에 추가한다.
- 선택지 연결은 Key로 식별한다. 배열 순서를 바꿔도 유지하며 삭제/변경 시 끊긴 참조를 명시적으로 처리한다.
- 변수 목록은 Bool Key/초기값. 재생 초기값 override 제공. 시나리오 밖의 상태 저장은 하지 않는다.
- 경로 해석은 DAG의 활성/미선택/미결정 연결을 구분한다. 미결정 선택지에서 멈추고, 선택 후 새로 활성화된 구간만 이어 간다. 모든 경로가 합류해도 선택하지 않은 입력을 기다리지 않는다.
- Ruling: 기존 스케줄러를 런타임 공통 모듈로 옮겨 선택된 누적 경로만 일시 시퀀스로 생성한다. 매 결정 시 이전 시간 경계부터 새 구간으로 이동한다. 모든 경로의 완성 시퀀스를 저장하지 않는다. 누적 경로는 현재 값 이동의 시작 자세 계산을 기존 검증된 스케줄러로 유지하기 위한 내부 표현이며, NPC/카메라는 전체 실행 세션 소유로 바인딩한다. 단순 그래프의 기존 단일 시퀀스 방식은 유지한다.
- 병렬 경로 안의 미합류 결정 지점은 생성 오류로 안내한다. 분기 앞에 합류를 사용하도록 한다. 순환은 지원하지 않는다.

## 검토 기준
분기 생성이 원본 애셋이나 기존 시퀀스를 파괴하지 않음. 새 시퀀스가 이전 구간의 게임 이벤트를 중복 실행하지 않음. 생성 NPC의 소유권이 구간마다 이동하지 않음. 클릭 프레임의 후속 일반 대사 건너뛰기 차단. 대기·중단·오류·재실행이 입력/HUD와 바인딩을 복구함.
