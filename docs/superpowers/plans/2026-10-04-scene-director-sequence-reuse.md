# 레벨 시퀀스 재사용 구현 계획

목표: 수동 제작한 Level Sequence를 원본 수정 없이 그래프에서 재생. 속도/완료 대기, 역할별 NPC·카메라 연결과 미리보기 지원.
실행: 기존 승인 계획의 다음 기능. 현재 작업 공간에서 직접 구현.
구조: 원본을 생성 시 복제하여 SubTrack에 삽입. 커스텀 바인딩이 부모 그래프의 실제 Actor를 공통으로 해석하므로 미리보기와 런타임이 같은 데이터 사용. 원본의 재생 범위와 틱 해상도를 유지한다.

## 범위
- 속도 > 0, 자동 시간 계산, 순차/병렬 일정 및 분기 경로 처리.
- 원본 Spawnable 자체 사용 또는 그래프 NPC/카메라 Key 연결. Possessable은 역할 연결 필수.
- Actor 밑 단일 컴포넌트 바인딩은 원본 클래스와 이름으로 연결. 중복/없는 컴포넌트는 생성 오류.
- Transform, Skeletal Animation, Camera Cut, 기본 수치/색상/가시성, Audio 트랙을 지원. Event/중첩 서브시퀀스/Control Rig/동적 바인딩 실행 등 미지원 종류는 오류로 안내한다.
- 원본 시간 범위 밖의 트랙은 재생하지 않는다. 끝나면 부모 그래프 상태로 복구한다. 기존 현재값 이동의 시작 자세를 원본 끝 자세로 자동 변경하지 않는다.
- 같은 대상/카메라의 겹치는 연출은 오류로 안내. 미선택 경로의 시퀀스는 생성 결과에 넣지 않는다.
- 컴파일 실패 시 마지막 생성물 보존. 사용자 애셋 변경 시 생성 및 미리보기로 재생성.

## 구현 중 확인한 사항
- 원본 Spawnable의 실제 템플릿 메시로 애니메이션 호환성을 검사하며, 자식 컴포넌트는 클래스와 이름으로 구분한다.
- 복사본에서만 잠금/읽기 전용을 해제하여 네이티브 TrimSection으로 오디오·애니메이션 위상을 보존한다. 범위 제한 실패 시 생성을 중단하고 마지막 결과를 유지한다.
- 오디오 Play Until Finished, 프리롤/포스트롤/가장 가까운 섹션 평가는 복사본에서 끈다.
- 원본 트랙·행·섹션 조건 실행을 거부하고, 대상 Key 중복은 FName 규칙으로 검사한다.
- 독립 편집기는 카메라 캐시가 없으므로 활성 서브시퀀스의 바인딩과 시간 변환을 이용해 촬영 카메라를 미리보기에 적용한다.
