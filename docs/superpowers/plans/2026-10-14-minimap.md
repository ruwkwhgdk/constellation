# School Minimap Implementation Plan

**Goal:** Apply the approved constellation-rim minimap to the actual AbandonedSchool level, with wall/floor-aware exploration and persistent discovery.
**Architecture:** Authored region data contains separate floor grids and semantic markers; GameInstance persistence owns monotonically merged discovery; a world subsystem samples active pawn and resolves active quest; native Slate paints a clipped north-up player-centered view. Editor generation reads actual structural meshes and semantic actors, preserving overrides by stable source identity.
**Tech Stack:** UE 5.8 C++ / UMG-Slate / Unreal Python migration and PIE validation.
**Spec:** ArtSource/UI/Minimap/Concepts/2026-10-14/implementation-handoff.txt (already approved for implementation).

## Constraints and decisions
- Preserve concurrent workspace changes and existing HP/ST bottom-center HUD with no text labels.
- Stay in the active project checkout: existing uncommitted assets and build/editor integration are required; do not fork an incomplete asset snapshot.
- No additional design approval: the supplied handoff explicitly requests implementation of the approved behavior.
- Do not create imaginary objective positions. Reuse tracked quest TargetPositions[InnerProgress], with optional explicit region/floor override and clear off-floor label.
- Exploration is monotonic within the current GameInstance and merged into the latest shared save on existing save events and bounded dirty flush, not written every frame.
- Current map includes variable-height cave/ladder paths; audit real geometry before committing floor strata. Unidentified connection geometry stays an explicit candidate rather than an invented stair.

## Review focus
- Thin walls and diagonal raster corners must never reveal a neighboring room.
- Different floors with overlapping XY must not share exploration, markers or misleading objective glyphs.
- A stale currency/quest/scene save must not discard pending exploration or other persistent fields.
- Regeneration must preserve stable-ID marker exceptions and previously discovered world cells.
- Possession, world transitions, DPI and circular-edge clipping must not alter gameplay input.
