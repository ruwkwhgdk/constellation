# Golden Orbit QTE Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement and review bounded tasks. Shared checkout is intentional: preserve the user's in-progress Unreal assets and existing plugin work. Do not create an alternate implementation checkout, clean Intermediate, or compete with another build.

**Goal:** Four transparent, mouse-driven QTE presentations with real SceneDirector success/failure branches and cancellation cleanup.
**Architecture:** Deterministic input state machine in SceneDirectorRuntime; Slate overlay draws individual vector elements and owns pointer handling; SceneDirector starts and resolves one QTE and restores controller/focus state. Existing graph branching/compiler conventions are extended, not replaced.
**Tech Stack:** Unreal 5.8, C++, Slate, Unreal automation and isolated PIE.
**Spec:** ArtSource/UI/QTE/Concepts/2026-10-21/implementation-handoff.txt (approved design and reference PNG).

## Global constraints
- Transparent overlay only; no sheet background, titles, captions, numbers or large panel.
- Gold orbit/stars, ivory inputs and one continuous remaining-time arc.
- Click, independent repeated clicks, directional drag, ordered curved tracing.
- Unlimited retries without timer; timed retry or explicit immediate failure.
- Fresh button press after appearance; exactly one result; cancel is not failure.
- Hold scene or continue scene policy distinct from engine pause. No invented hold animation.
- Restore input, cursor and focus on all exit paths; freeze timer/input when paused or unfocused.
- No shared build cleanup; preserve other tasks' modifications and existing assets.

## Review focus
- Held mouse crossing prompt boundaries must not count.
- Teleport to trace endpoint must fail/retry, not shortcut progression.
- Result callbacks can stop/destroy/restart a scene; latch before callback.
- Focus loss, resize/DPI and pause cannot consume hidden time or relocate active targets.
- Consecutive nodes and cancellation must restore exactly the prior interaction state.

- [ ] Core: create DirectorQTE.h/.cpp with settings, validation, deterministic state and regression tests covering all four types, time boundaries, retries, pause, cancellation and input freshness.
- [ ] Presentation: create SDirectorQTE.h/.cpp with vector visuals, generous hit areas, mouse events, guide demonstration, local outcome animation and configurable sound hooks. No raster sheet dependency.
- [ ] Integration: append QTE node enum, settings and Success/Failure output pins; extend compiler/branch resolver; integrate player QTE lifecycle, time policy and cleanup. Add graph/runtime tests and a sample scene asset generation script.
- [ ] Validate: run one coordinated incremental build, relevant automation tests, actual node success/failure/cancel/repeat PIE and screenshots across bright/dark backgrounds and DPI. Inspect outputs rather than substituting mockups.
- [ ] Deliver: document node usage, resources, verified results and any unconnected sound hooks or unverified cases. No push unless requested.
