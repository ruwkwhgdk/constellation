# 주인공 물건 들기·내려놓기·던지기 설계

2026-10-01. 사용자가 채팅에서 승인한 기획을 구현 기준으로 기록한다. 이 문서는 기능 완료 보고가 아니다.

## 목표와 범위

싱글플레이 여주인공이 단일 강체 물건 하나를 양손으로 운반한다. 기존 상호작용 키로 집기·내려놓기, 기존 공격 키인 마우스 좌클릭의 누름·해제로 조준·투척한다. 충전 투척, 네트워크 복제, 여러 물리 몸체의 물건은 이번 범위에 포함하지 않는다.

## 게임 규칙

- 캐릭터 게임플레이 무게의 20% 이하인 물건을 들 수 있다. 초기 조정값은 캐릭터 50kg, 한계 10kg이며 에디터에서 변경 가능하다.
- 운반·조준 중 걷기, 방향 전환, 카메라 조작을 허용한다. 공격·점프·회피·대시·변신과 충돌하는 상호작용을 차단한다.
- 집기·내려놓기·투척 중 이동을 제한하며 회복 동작이 끝날 때까지 다른 액션을 차단한다.
- 내려놓기는 현재 캐릭터 앞의 바닥에 한다. 집었던 원래 위치로 이동시키지 않는다.
- 조준 중 상호작용 키는 조준만 취소한다. 다음 상호작용 입력으로 내려놓는다.
- 좌클릭 유지 시간은 충전량으로 쓰지 않는다. 카메라 조준을 반영하고 캐릭터를 목표 방향으로 회전시킨다.
- 투척 불가 상태에서 해제하면 발사하지 않고 운반 상태로 돌아간다.

## 구성

`UHoldableComponent`를 부모로 하는 `Ac_Holdable` Blueprint는 운반 대상 메시, kg 단위 질량, 잡는 오프셋, 좌우 손 접촉 Transform, 내려놓기 방향, 투척 허용 여부를 설정한다. 적용 대상은 단일 강체 충돌체를 가진 물건이다.

`UCarryComponent`는 플레이어의 물건 참조, 상태, 집기 조건, 부착·분리, 배치 검사, 투척 속도, 미리보기와 복구를 소유한다. Blueprint에 입력 함수와 애니메이션 이벤트 함수를 공개한다. 기존 입력과 상태 시스템을 대체하지 않고 기존 액션 진입점에서 해당 컴포넌트의 허용 여부를 확인한다.

상태는 `Idle`, `PickingUp`, `Carrying`, `Aiming`, `Placing`, `Throwing`으로 구분한다. 각 전환에는 현재 상태와 대상 유효성 검사가 있다. 반복 입력과 중복 애니메이션 이벤트는 물건을 두 번 부착하거나 발사하지 않는다.

## 물리·배치·예측

운반 전 물리·충돌·이동 설정을 저장한다. 운반 중 물리 시뮬레이션을 끄고 캐릭터 운반 소켓에 부착한다. 내려놓기와 투척 시 적절한 물리 설정으로 복구한다. 다른 물체를 밀고 벽을 통과하는 운반을 막기 위해 물건 공간을 함께 검사한다.

배치는 바닥 위치, 경사, 물건 전체 충돌 형태, 캐릭터와의 겹침, 손에서 배치 위치까지 경로를 확인한다. 바닥 접촉 자체는 실패로 처리하지 않는다. 애니메이션 시작과 분리 이벤트에서 재검사하며 실패 시 운반으로 복귀한다.

예측과 투척은 동일한 중력·초기 속도·발사 위치 정의를 사용한다. 예상 발사 자세를 기준으로 조준 중 예측하고 분리 이벤트에서 실제 공간을 재검사한다. 직사각형 물건은 방향을 반영하는 형상 검사로 좁은 벽과 천장을 확인한다. 지원 형상의 실제 충돌체와 검사 형태의 차이를 테스트한다.

반투명 물건은 **최초 도달/충돌 위치**를 나타낸다. 튀거나 굴러간 뒤 최종 정지 위치를 보장하지 않는다. 시각용 메시에는 충돌·상호작용을 부여하지 않는다. 유효 위치는 청록, 불가 위치는 적색으로 표시한다. 조준 종료 즉시 제거한다.

월드 Z축 각속도는 거리 비율에 따라 증가한다. 최대 거리에서 최초 도달까지 약 90도 회전하는 값을 초기 목표로 두고 물건별 물리 감쇠를 반영해 조정한다. 투척자가 물건을 즉시 맞지 않도록 일시적으로 자기 충돌을 제외하고 충분히 분리되면 복구한다.

## 애니메이션과 UI

집기, 내려놓기, 던지기, 운반 대기, 운반 걷기, 조준 유지 자세를 전달한다. 기본 검토 물건은 중형 상자다. 기존 160cm 여주인공 비율, 얼굴과 의상 스타일, 94본 게임 스켈레톤을 보존한다.

집기 접촉, 내려놓기 분리, 투척 분리 이벤트에서 실제 물건 전환을 실행한다. 몽타주 종료/중단 시 상태를 복구한다. 손 IK, 발 접지, 무게 이동, 의상·물건 간섭과 게임 내 전환을 각각 검증한다. Blender 배치는 반드시 `tools/run-blender.ps1`을 사용하고 프로필 검사 실패 시 해당 작업에만 정상 사용자 실행 승인을 요청한다.

화면 중앙 아래에 다음 메시지를 2초 표시한다. 동일 메시지는 중첩하지 않고 시간을 갱신한다.

- 너무 무거워서 들 수 없습니다.
- 공간이 부족해 내려놓을 수 없습니다.
- 이 위치로 던질 수 없습니다.

## 복구와 검증

피격·사망·물건 파괴·맵 종료·몽타주 중단 시 부착, 충돌 제외, 이동 설정, 미리보기, 대상 소유권을 정리한다. 일반 상태로 복귀할 때 이미 죽거나 시네마틱 중인 플레이어의 액션을 강제로 허용하지 않는다.

완료 조건은 컴파일과 자동 테스트, 저장 후 Blueprint 재로드·컴파일, 실제 플레이, 애니메이션 시각 검토를 모두 포함한다. 자동 테스트만 통과한 상태를 기능 완성으로 보고하지 않는다. 기존 환경 맵은 수정하지 않고 별도 기능 검토 맵을 사용한다.
