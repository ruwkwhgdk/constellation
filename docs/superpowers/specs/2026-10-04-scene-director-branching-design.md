# 대화 선택지와 조건 분기 설계안

기획자가 선택지와 조건을 노드로 연결하고, 실제로 선택된 경로만 재생하도록 확장한다. 사용자가 승인한 다음 작업 분야는 대화 선택지·조건 분기이며, 구현 및 검증을 완료했으며, 세부 구현 결정은 ../plans/2026-10-04-scene-director-branch-execution.md에 기록한다.

## 기획자 작업 방식

- 기존 대사 노드의 선택지 배열을 사용하고 우클릭 메뉴에 **조건 분기**, **변수 설정**을 추가한다.
- 대화 선택지: 화자, 질문, 선택지 문구를 입력한다. 선택지는 최대 4개이며 각 항목에 고유 ID와 별도 출력 핀이 있다. 문구 변경이나 목록 순서 변경으로 연결이 바뀌지 않는다. 항목 삭제는 해당 연결도 제거하며 Undo로 복원한다.
- 조건 분기: Bool 변수의 참/거짓을 검사하고 대응하는 출력 핀 하나만 실행한다. 변수 설정 노드는 Key와 값을 입력한다.
- 오른쪽에 NPC·카메라·Vector3와 구분된 **조건 변수** 영역을 추가한다. String Key와 초기 Bool 값을 등록한다. 이번 단계는 Bool부터 지원하고 수치 비교와 저장 게임 연동은 별도 확장한다.
- 변수는 연출 재생마다 초기값으로 시작한다. 분기 사이에서는 유지하고, 재생 종료 시 외부 게임 데이터에 자동 저장하지 않는다. 블루프린트에서 재생 시작 전 초기값을 제공할 수 있는 진입점을 마련한다.

## 화면과 입력

- 현재 대화창에 질문을 표시하고, 제공된 선택지 배경 애셋을 사용한 선택지 목록을 대화창 위 오른쪽에 배치한다. 대화 본문을 덮지 않으며 화면 크기에 맞춰 축소한다.
- 마우스 클릭 또는 위/아래 방향키와 Enter로 선택한다. 선택지 대기 중에는 일반 대사의 Space/Enter 처리와 하단 진행 화살표를 차단해 이중 진행을 방지한다.
- 선택 전에는 연출 시간이 멈추고, 선택 시 한 항목만 확정된다. 중복 클릭과 같은 프레임의 중복 입력은 무시한다. 선택하지 않은 경로의 음성·NPC 생성·카메라·변수 설정은 실행하지 않는다.

## 그래프 규칙

- 일반 출력의 복수 연결은 기존처럼 병렬 실행한다. 선택지 출력과 조건의 참/거짓 출력은 서로 배타적인 경로다.
- 분기 결정은 앞서 시작된 병렬 작업을 모두 마친 경계에서 수행한다. 병렬 작업 중간에 선택지나 조건이 끼어드는 구조는 생성 시 구체적인 오류로 안내하며 합류 뒤로 옮기도록 한다.
- 여러 분기가 합류하면 이번 실행에서 활성화된 경로만 기다린다. 선택하지 않은 경로를 기다려 멈추거나 같은 합류 이후를 중복 실행하지 않는다.
- 이번 단계는 순환 없는 그래프를 유지한다. 모든 선택지, 참/거짓 출력은 연결되어야 하며 모든 경로는 종료에 도달해야 한다.
- 알 수 없는 변수, 중복 Key, 비어 있는 문구, 끊긴 분기, 선택한 경로에서 생성되지 않은 NPC 참조를 생성 전에 검사한다. 실패하면 이전 생성물을 부분적으로 덮어쓰지 않는다.

## 실행 구조

현재 컴파일러는 전체 그래프를 하나의 고정 타임라인으로 만들고, 실행기는 그 타임라인의 시간을 진행한다. 모든 경로를 미리 같은 시퀀스에 넣고 나중에 시간만 건너뛰는 방식은 미선택 경로의 트랙 평가와 상태 변경 위험이 있어 채택하지 않는다.

구현은 **선택한 누적 경로를 임시 시퀀스로 생성하고 이전 결정 경계부터 이어서 실행**한다. 런타임 공통 컴파일러가 기존 시간·병렬 스케줄러와 현재 값 이동 계산을 재사용한다. 결정 지점에서 선택 UI나 조건 평가가 다음 경로를 정한다. 이미 실행한 이벤트는 중복 실행하지 않으며 단순 그래프는 기존 단일 시퀀스 경로를 유지한다.

NPC·카메라 바인딩, 변수, 최초 위치 및 입력/HUD 복구 상태는 전체 재생 세션이 소유한다. 구간 전환이 기존 StopDirector 전체 정리를 호출하지 않도록 분리한다. 생성 NPC는 세션에서 유지하고 다음 시퀀스는 동일한 액터에 바인딩한다. 실제 종료·중단·실패 때만 생성물을 제거하고 기존 액터와 조작 상태를 복구한다. 앞 경로의 이동 결과가 다음 구간의 현재 값 계산에 이어지도록 구간 진입 시 시작 자세를 전달한다.

대안인 모든 경로의 완성 시퀀스 사전 생성은 중첩 선택지 수에 따라 결과가 급격히 늘어나므로 채택하지 않는다. 별도 이벤트 그래프로 강제 이동하는 방식은 같은 그래프 안의 분기·합류 편집 목적에 맞지 않는다.

## 미리보기

미리보기 경로 선택에서 선택지 응답과 조건 변수 초기값을 지정하고, 해당 경로만 생성해 타임라인에서 탐색한다. 어떤 답변 경로인지 화면에 표시한다. 실제 클릭 입력 및 대기 동작은 게임 실행에서도 별도로 검사한다. 미리보기를 끝내거나 경로를 바꾸면 임시 액터·음성·상태를 정리한다.

## 완료 기준과 검증

1. 기존 그래프와 26개 자동화 테스트가 그대로 통과한다.
2. 선택지 A/B 각각에서 선택한 경로만 실행되며 미선택 경로의 음성, 생성 및 변수 변경이 발생하지 않는다.
3. 조건 참/거짓, 변수 설정 후 조건 재검사, 잘못된 Key 오류를 검증한다.
4. 중첩 선택지와 합류에서 무한 대기·중복 실행이 없다. 병렬 구간과 분기 경계 오류도 검증한다.
5. 선택지 편집·순서 변경·삭제·Undo·저장 후 재열기에서 핀 연결이 유지된다.
6. 구간 전환 시 NPC가 재생성되거나 위치가 초기화되지 않고, 현재 값 이동 계산과 카메라 연속성이 유지된다.
7. 대기 중 중단, 재실행, 큰 프레임 지연, 중복 입력, 종료 후 카메라·조작 복구를 검증한다.
8. 선택지 예제 그래프와 사용법을 제공한다. 한글 선택지 줄바꿈, 긴 문구, 작은 미리보기 화면을 실제 렌더링으로 확인한다.

## 구현 순서

데이터·핀·변수 편집 → 경로 검증 및 구간 생성 → 세션 실행기와 바인딩 유지 → 선택지 UI 및 입력 → 경로 미리보기 → 예제·회귀 검증 순으로 진행한다. 세부 구현 결정 및 완료 검증은 구현 계획서에 기록한다.


## 선택지 UI 리소스 확정

사용자 추가 지시: 최대 4개. BG/Stroke는 포커스 항목, BG2/Stroke2는 비포커스 항목, 별도 오른쪽 삼각형 이미지는 커서다. B 버튼은 표시하지 않는다. 다운로드 폴더의 원본을 보존하고 프로젝트용 이름으로 복사·임포트한다.
